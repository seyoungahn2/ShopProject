- **기간:** 2024.03 ~ 2026.03 (2년 1개월)
- **직무 태그:** 데이터분석

**담당 업무**
1. 브랜드 총 250여 개점(170여 호점) 운영 관리
2. 샵인샵 브랜드 중복 입점 관리
3. 분산된 가맹점 데이터를 1페이지로 취합·재정립
4. **가맹점 관리 시트 개발(엑셀)**
   - 검색 전용 대시보드 페이지
   - 가맹점 로열티 납입 현황 데이터 페이지
   - 가맹점 계약·입점 브랜드·매장 정보 데이터 페이지
   - 지역별 매장 분류·출력 데이터 페이지
   - 운영팀 운영일지 연동 Daily To-do List
   - 일일 운영 매출 데이터 산출 페이지
   - 가맹점 물류 매출 데이터 취합 페이지
5. **가맹점 운영 관리**
   - 매출·운영 모니터링 및 통제
   - 가맹점 프로모션 기획
   - 유선/방문 상담 QSC
   - 고객 CS 처리
   - 배달앱(배민, 쿠팡, 요기요) B2B 관리
6. **가맹점 계약 관리**
   - 계약서 작성·발송 매뉴얼 제작
   - 영업 시 정보공개서·계약서 작성 및 발송
   - 2주 후 본계약 작성·서명 체결 관리
   - 사업자등록증, 영업신고증, 개인정보 관련 서류 관리

### 3-2. 위드인푸드 — 운영기획 프리랜서 실장 / 사업기획
- **기간:** 2020.11 ~ 2023.06 (2년 8개월)

#### A. 교육팀 (2020.11 ~ 2021.10, 1년)
1. 신규·양도양수 점주 대상 이론·실무 매뉴얼 교육
2. 교육 매뉴얼 제작·수정·보완, 교육 도구(휴대용 매뉴얼북) 제작
3. 직영점 운영 관리 (위생 FQMS, 음식점 위생등급)
4. 조리고등학교 M.O.U. 체결, 요리경연대회 기획·진행

#### B. 사업기획·법무·행정
1. 서류 취합 총괄, 계약 내용 검토
2. 가맹거래사·변호사와 협의하며 정보공개서 개정·보완
3. 양도양수·폐점 상담 및 처리
4. **사업기획**
   - 매출·물류·시장·경제 동향 모니터링
   - 데이터 기반 원인 분석 → 인사이트 도출 → 프로모션 기획
   - 사업 방향성 제안
   - 신규 브랜드 개발 참여

#### C. 운영지원실 (2021.11 ~ 2023.06, 1년 7개월)
1. 푸드테크 POS 메뉴 생성·수정·삭제 관리
2. 배달/서비스 플랫폼 8곳 메뉴 템플릿 관리 (배민, 요기요, 쿠팡이츠, 네이버 등)
3. POS·API 코드 기반 본사 메뉴보드 관리
4. 스마트온 매출분석 시스템으로 가맹점 매출 통계·분석, 물류 사업 검수
5. 자체 회사 앱 도입 기획·실행
6. CS(고객·가맹) 응대, 물류 반품 관리
7. 공지·대외 공문 작성, 배달앱 입점 신청 대행

#### D. 운영지원 성과 요약 (경력기술서)
1. 고객 CS + 가맹 CS 피드백 직접 취합 → 통계 기반 개선안 제안
2. 물류 발주 현황 모니터링 및 개선안 제안
3. 앱사·물류사 커뮤니케이션 관리·통제
4. 배달앱 가맹·본사 메뉴보드 관리
5. **반자동화 통계 프로그램 설계·배포**
6. 조리고 협약(MOU)·요리경연대회 기획·진행
7. 발주 모니터링·검수용 엑셀 도구로 효율·정확도 향상
