## Q. 왜 통장에 ‘매달 같은 날·같은 금액’이 안 들어오나?

종목·ETF마다 **결산·분배 정책**이 다르고,
기준일과 실제 입금일 사이에 **시차**가 있습니다.
환율·성과·분배 가능 이익에 따라 금액도 달라질 수 있습니다.

## 1. 용어만 먼저

| 용어 | 의미 |
| :--- | :--- |
| **기준일(배당기준일)** | 이 날 주주 명부에 있어야 배당 권리 |
| **지급일** | 실제 계좌에 현금(또는 재투자) 반영 |
| **분배금** | ETF·펀드가 나눠 주는 현금 흐름(성격은 상품마다) |

현금흐름 표의 날짜 축은 **지급일**을 추천합니다.

## 2. 주기 유형 (개념)

| 유형 | 특징 | 현금흐름 팁 |
| :--- | :--- | :--- |
| **월** | 입금 빈도가 높음 | 생활비와 맞추기 쉬움, 금액 변동 확인 |
| **분기** | 3·6·9·12 등에 몰림 | 분기 평균으로 월급처럼 환산 |
| **반기·연** | 드묾 | 버퍼 없이 생활비로 쓰기 어려움 |

한 계좌에 주기가 다른 상품이 섞이면 **합산 월 표**가 필요합니다(8화).

## 3. 실무에서 적는 법

1. 증권사 앱에서 **최근 12개월 배당·분배 입금** 내보내기
2. 월별로 합산
3. **중앙값·최솟값**을 같이 적어 낙관 금지

```
예(가정): 3월 12만 / 4월 3만 / 5월 8만 → “월 평균 7.7만”만 보지 말고
          “최솟값 3만”을 생활비 하한으로
```

## 4. ISA vs 일반 — 주기 자체는 같음

같은 ETF면 **분배 주기**는 계좌가 달라도 유사합니다.
달라지는 것은 **세금·인출·한도**(3~6화)입니다.
