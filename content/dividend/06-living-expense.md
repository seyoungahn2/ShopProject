# 배당으로 생활비 쓸 때, 인출·이체 루틴 | 배당현금흐름 (6화)

안녕하세요.
안대표입니다.

분배금이 들어왔을 때 **바로 카드값을 막으면** 편하지만, 규칙이 없으면 표가 무너집니다.
이번 6화는 생활비로 쓰는 **이체 루틴**입니다.

## 30초 요약

- 생활비로 쓸 금액은 **세후·최솟값** 기준으로 상한을 둡니다.
- 추천 흐름: 입금 → 버퍼 → **고정 이체** → 잔여 재투자/유지.
- ISA는 **원금 인출**과 분배금 사용을 혼동하지 마세요.

→ **2화: 지급일 달력**
→ [ISA 8화: 원금 중도인출](https://mynews20482.tistory.com/8)

## Q. 배당이 들어오는 날 바로 써도 될까?

가능합니다. 다만
- 그다음 달 **최솟값**보다 많이 쓰면 적자가 납니다.
- ISA에서 부족분을 **수익까지 인출**하면 혜택 이슈가 생길 수 있습니다.

## 1. 권장 루틴 (단순)

1. 분배·배당 **입금**  
2. **생활비 통장**으로 미리 정한 금액만 이체  
3. 남으면 ISA/일반에서 **재투자 또는 버퍼**  
4. 부족하면 **비상금** — 투자 원금 훼손은 최후

## 2. 상한 정하는 법 (가정)

| 기준 | 예시 |
| :--- | :--- |
| 최근 12개월 월 세후 **최솟값** | **8만** |
| 생활비 상한 | **최솟값의 70%~80%** → 약 **6만** |
| 나머지 | 재투자·버퍼 |

숫자는 가정입니다. 핵심은 **낙관 평균이 아니라 최솟값**입니다.

## 3. ISA에서 생활비를 댈 때

| 하면 | 주의 |
| :--- | :--- |
| 분배금을 출금·이체 | 상품·앱 절차 확인 |
| 원금 중도인출 | **한도 복구 안 됨**, 혜택 규칙 |
| 수익까지 출금 | 해지·추징 리스크 가능 |

생활비의 본진은 **급여+비상금**, 배당은 **보조**로 두는 편이 마음이 편합니다.

## 4. 이체 규칙 문장 예시

> “매월 분배 지급일 다음날, 세후 확정분 중 **최대 6만 원**만 생활비 통장으로. 초과분은 손대지 않음.”

## 핵심 숫자

| 항목 | 내용 |
| :--- | :--- |
| **상한** | 12개월 세후 **최솟값**의 일부 |
| **비상금** | ISA와 **분리** |
| **ISA 인출** | 원금 범위·한도 감소 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 평균 분배로 고정비 늘리기 | **최솟값** 기준 |
| 부족분을 ISA 해지로 해결 | **비상금·원금 인출** 순서 |
| 입금 즉시 전액 소비 | **버퍼→상한 이체** |
| 부부 각자 규칙 없음 | 가구 **생활비 통장 하나** |

## 이번 화 전략

**초보**
- 이번 달 분배금의 **절반만** 생활비 실험.

**직장인**
- 배당 생활비는 **가변비**에만 — 월세·대출은 급여로.

**부부**
- 생활비 통장으로의 이체 **한도**를 공유 캘린더에.

## 확인 권장

## 핵심 정리

1. 생활비는 **세후 최솟값 상한**이 안전장치입니다.
2. 입금 → 버퍼 → 이체 순서가 표를 지킵니다.
3. ISA 부족분은 **해지보다 비상금·규칙**입니다.
