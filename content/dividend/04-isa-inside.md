# ISA 안 배당, 손익통산·비과세에 연결하기 | 배당현금흐름 (4화)

안녕하세요.
안대표입니다.

ISA 안에서 분배금이 들어오면 “세금이 없는 월급”처럼 느껴질 수 있습니다.
이번 4화는 그 감각을 **손익통산·비과세 한도**에 다시 연결합니다.

## 30초 요약

- ISA 분배금은 계좌 **과세 수익**의 일부로, **종목별 15.4%**와 다르게 움직입니다.
- 비과세는 **계좌 순이익** 기준 **200만·400만** — 배당만의 별도 한도가 아닙니다.
- 월 현금흐름과 **연간 순이익 트래킹**을 같이 두는 편이 안전합니다.

## Q. ISA 분배금을 생활비로 써도 되나?

가능합니다. 다만
1) **원금 중도인출** 규칙과 혼동하지 않기  
2) 분배금을 쓰더라도 **계좌 순이익·한도**는 계속 움직이기  
를 기억하세요.

## 1. 월 유입 vs 연 정산

| 관점 | 보는 것 |
| :--- | :--- |
| **월** | 분배금 입금 → 생활비/재투자/버퍼 |
| **연·계좌** | 손익통산 후 **순이익** → 200·400·9.9% |

월 표만 보면 세금이 “없는 달”처럼 보여도, 연간으로는 B·C층(3화)이 남습니다.

## 2. 가정 스케치

| 항목 | 가정 |
| :--- | :--- |
| ISA 분배금 연합 | **300만** |
| 다른 과세 손익 | 통산 후 순이익 **250만** |
| 일반형 비과세 | **200만** |
| 초과 감각 | **50만** × 9.9% 참고 |

숫자는 예시입니다. 중요한 건 **분배금 ≠ 비과세 한도 자체**라는 점입니다.

## 3. 현금흐름 운영 팁 (ISA 안)

1. 분배금 입금 → **버퍼**에 잠시  
2. 그달 생활비 필요분만이체  
3. 나머지는 재투자 또는 유지  
4. 분기마다 **순이익·한도 진행** 메모(ISA 44화 루틴과 연결)

## 4. 서민형이면

비과세 **400만**으로 여유가 생깁니다.
그래도 “배당만 400만”이 아니라 **계좌 순이익**입니다.

## 핵심 숫자 (2026-07)

| **비과세** | **200만·400만**(순이익) |

| **해외 직접** | **불가** — 국내상장으로 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 분배금=완전 비과세 월급 | **순이익 한도**와 같이 보기 |
| 종목별 세금 계산 | **계좌 통산** |
| 비과세 맞추려 잦은 매매 | 한도는 **참고**, 비용 주의 |
| 수익까지 중도인출 | **원금 범위**·혜택 리스크(ISA 8화) |
