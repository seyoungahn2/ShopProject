## Q. 왜 ‘조금만’이 위험한가?

분배금은 작아 보여도 **고정비를 올려 버리면** 공백 달에 적자가 납니다.
조금만 올린 구독·할부가 표를 배신합니다.

## 1. 실수 → 처방

| 실수 | 처방 |
| :--- | :--- |
| **평균**으로 고정비 상향 | **최솟값** 상한 |
| **세전**으로 이체 | **세후** |
| 몰림 달 **과소비** | 상한 **고정**(10화) |
| ISA **해지**로 생활비 | 비상금·원금 규칙 |
| ISA·일반 **한 줄 합산** | **행 분리** |
| 재투자 **올인** 후 급전 | 버퍼 **비율** |
| 종합과세 **무시** | 연간 합계 메모(5화) |
| 표 **안 적음** | 월 8화 5분 |

## 2. 한 줄 복구 프로토콜

공백 달이 오면:

1. 생활비 이체 **일시 0**  
2. 급여·비상금으로 통과  
3. 다음 몰림 달에도 상한 유지  
4. 표에 “깨짐 원인” 한 줄
