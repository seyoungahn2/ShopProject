- 금융소득이 커지면 **종합과세·ISA 가입 이력**을 같이 봅니다.

## Q. 왜 ISA만으로 배당 현금흐름을 안 끝내나?

- 해외 **직접**은 ISA 불가  
- 연·총 **납입 한도**  
- 이미 일반에 쌓인 배당주·ETF  

역할 분담이 없으면 세금·중복·심리 관리가 어렵습니다.

## 1. 역할 예시

| 계좌 | 배당·분배 역할 |
| :--- | :--- |
| **ISA** | 국내상장 배당·해외지수 ETF 분배 — 절세 레이어 |
| **일반** | 해외 직접 배당, 실험·단기 |
| **통장** | 생활비·비상금 — 투자와 분리 |

## 2. 월 표에 넣는 법 (일반)

| 칸 | 내용 |
| :--- | :--- |
| **세전** | 입금 총액 |
| **세후 가정** | × **(1−0.154)** |
| **사용** | 생활비 / 재투자 / 보류 |

## 3. 중복 체크

S&P 분배가 ISA에도, 일반 해외주식 배당에도 있으면
**지역·섹터 노출**이 겹칩니다.
현금흐름만 합치면 “안전한 월급”처럼 보여도, 리스크는 한곳에 있습니다.

## 4. 종합과세 문턱 (주의)

이자·배당 합이 커지면 종합과세 이야기가 나옵니다(문턱으로 **2,000만**이 자주 언급).
ISA 가입·재가입과도 연결될 수 있어, **현금흐름이 커질수록** 5화와 ISA 28화를 같이 보세요.

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |

| 배당만 늘리고 종합과세 무시 | **연간 금융소득** 메모 |
| 비상금을 일반 배당계좌에 | **통장 분리** |
