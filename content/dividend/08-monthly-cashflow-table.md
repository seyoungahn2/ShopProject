# 월급처럼 보는 월별 배당 현금흐름 표 | 배당현금흐름 (8화)

안녕하세요.
안대표입니다.

이번 8화가 시리즈의 **핵심 표**입니다.
지급일·세금·생활비·재투자를 한 달에 한 장으로 합칩니다.

## 30초 요약

- 월별 표 열: **세전 유입 / 세후 가용 / 생활비 / 재투자 / 잔액·메모**
- ISA와 일반은 **행을 분리**합니다.
- 숫자는 **가정 예시** — 본인 12개월 입금으로 교체하세요.

→ **2화·3화·6화·7화** (주기·세금·생활비·재투자)

---

## Q. 왜 엑셀 한 장이 필요한가?

머리가 기억하면 낙관이 섞입니다.
표는 **최솟값·공백 달**을 드러냅니다.

## 1. 기본 템플릿 (가정)

| 월 | ISA 세전 | 일반 세전 | 세후 가용(가정) | 생활비 | 재투자 | 메모 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | 5만 | 2만 | 약 **6.7만** | 4만 | 2.7만 | |
| **2** | 1만 | 0 | 약 **1만** | 0 | 1만 | 최솟값 근접 |
| **3** | 8만 | 3만 | 약 **10.3만** | 6만 | 4.3만 | |
| … | | | | | | |

일반 세후는 **15.4% 가정**, ISA는 예시에서 단순화했습니다.
실무에서는 ISA에 “정산 전” 라벨을 유지하세요(3·4화).

## 2. 작성 순서

1. 2화 — 12개월 **지급·금액** 채우기  
2. 3화 — 일반 **세후** 계산  
3. 6화 — **생활비 상한** 적용  
4. 7화 — 잔여 **재투자**  
5. 공백 달·최솟값에 형광펜

## 3. ‘월급처럼’의 의미

급여를 대체한다는 뜻이 아닙니다.
**매월 같은 양식**으로 보고, 변동을 견딘다는 뜻입니다.

## 4. 가구용이면

| 열 추가 | 내용 |
| :--- | :--- |
| **배우자 ISA** | 세전·사용 |
| **합산 세후** | 가구 생활비 상한과 비교 |

## 핵심 숫자 (템플릿 규칙)

| 규칙 | 내용 |
| :--- | :--- |
| **세후** | 생활비·재투자의 재료 |
| **상한** | 최솟값 기반(6화) |
| **분리** | ISA 행 / 일반 행 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 세전만 합산 | **세후 가용** |
| ISA·일반 한 줄 합치기 | **행 분리** |
| 한 달만 보고 고정비 상향 | **12개월** |
| 예시 숫자를 내 계획으로 | **본인 입금**으로 교체 |
