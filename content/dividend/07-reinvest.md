안녕하세요.
안대표입니다.

생활비로 쓰지 않는 분배금은 **다시 투자**할지, **현금으로 둘지**를 정해야 합니다.
이번 7화는 재투자 선택 기준입니다.

## 30초 요약

- 재투자는 **복리**에 유리하지만, 생활비·버퍼가 비면 의미가 줄어듭니다.
- 자동(재투자 설정)과 수동(모아서 매수) 모두 가능 — **수수료·최소 단위·한도**를 봅니다.
- ISA 안 재투자는 **납입 한도**와 별개로, 매수 여력·상품 범위를 확인하세요.

## Q. 무조건 재투자가 정답인가?

아닙니다.
고정비가 빠듯하면 **현금 버퍼**가 먼저입니다.
재투자는 “남는 현금흐름”의 처리입니다.

## 1. 세 가지 선택

| 선택 | 적합한 때 |
| :--- | :--- |
| **전액 재투자** | 생활비 상한을 이미 급여로 충족 |
| **일부 재투자** | 생활비 상한 이체 후 잔여 |
| **현금 유지** | 하락장 대비·큰 지출 예정 |

## 2. 자동 vs 수동

| 방식 | 장점 | 단점 |
| :--- | :--- | :--- |
| **자동 재투자** | 습관·누락 적음 | 금액·타이밍 통제 약함 |
| **수동** | 비중·버퍼 조절 | 미루면 방치 |

ISA·증권사마다 메뉴 이름이 다릅니다. **설정 가능 여부**만 확인하세요.

## 3. ISA에서 재투자할 때

- 분배금으로 같은 ETF를 사도 **해외 직접**이 되는 것은 아님  
- **연 납입 한도**는 “입금” 기준 — 분배금 재투수는 한도 소모와 다르게 움직이기도 함 → **금융사 안내 확인**  
- 리밸런싱이 필요하면 분기에만(ISA 20화)

## 4. 간단한 규칙 문장

> “생활비 상한 이체 후 잔여 분배금은 **같은 배당 ETF 70% / 버퍼 30%**.”

비율은 가정입니다. 문장만 있으면 8화 표에 옮기기 쉽습니다.
