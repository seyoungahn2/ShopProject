# 암·뇌·심장 진단비 | 보험점검 (4화)

안녕하세요.
안대표입니다.

진단비는 “걸리면 목돈”으로 이해하기 쉽지만, 실제로는 **약관에 정의된 진단**일 때만 지급됩니다.
암·뇌·심장 특약 이름만 보고 안심하면, 면책·유사암·뇌경색 vs 뇌출혈 같은 정의에서 기대와 어긋날 수 있습니다.
이번 화는 **이미 가입한 진단비 특약**을 읽는 법입니다.

## 30초 요약

- 진단비는 실손과 달리 보통 **정액**이며, 지급 여부는 **약관상 질병·진단 확정 기준**에 달립니다.
- 특약 이름보다 **보장 질환 정의·유사암·재진단·면책기간**을 확인합니다.

## Q. 실손이 있는데 진단비는 왜 보나?

실손은 의료비 영수증에 가깝고, 진단비는 **생활비·간병·비급여 공백**을 메우는 목돈에 가깝습니다.
역할이 다릅니다. “실손 있으니 진단비 불필요”는 가구 현금 버퍼에 따라 달라지며, 여기서는 **역할을 섞지 말 것**만 강조합니다.

## 1. 진단비가 묻는 세 질문

| 질문 | 증권·약관에서 |
| :--- | :--- |
| **무엇이** | 암 / 뇌혈관 / 심장 등 **정의된 질병** |
| **언제** | 진단 확정·입원·수술 등 **지급 사유** |
| **얼마** | 가입금액·감액·회당 한도 |

이름에 “뇌”가 있어도 **뇌졸중만**인지, **뇌혈관질환 전반**인지가 다릅니다.
심장도 **급성심근경색**과 **허혈성심장질환** 범위가 상품마다 달랐습니다.

## 2. 암 특약에서 자주 보는 포인트

| 항목 | 점검 |
| :--- | :--- |
| **일반암 vs 유사암·소액암** | 갑상선·기타피부 등 가입금액 축소 여부 |
| **면책·감액기간** | 가입 후 일정 기간 미지급·삭감 |
| **재진단·고도후유** | 특약 유무·정의 |
| **원발·전이** | 약관 조항 |
| **상피내암 등** | 별도 분류·금액 |

“암이면 무조건 가입금액 전액”이 아닙니다.
**진단서·조직검사 등 약관이 요구하는 증빙**도 미리 알아두면 청구 때 덜 당황합니다.

## 3. 뇌·심장 — 정의 표로 고정

보유 특약을 아래처럼 옮겨 적습니다.

| 특약명(증권) | 약관상 보장 질환(요약) | 가입금액 | 비고 |
| :--- | :--- | :--- | :--- |
| (예) 뇌졸중진단 | 약관 코드·정의 메모 | ○○만 | 뇌경색 포함 여부 |
| (예) 급성심근경색 | 정의·제외 | ○○만 | 협심증 제외 여부 |

인터넷 후기보다 **약관 조항 번호**를 메모하는 편이 안전합니다.
보험사 앱의 “보장 상세”만으로 부족하면 약관 PDF를 받습니다.

## 4. 중복 진단비와 가족 합산

정액 진단비는 실손과 달리 **중복 가입 시 각각 지급**되는 경우가 많습니다.
그렇다고 “많을수록 좋다”가 점검의 결론은 아닙니다.

| 상황 | 볼 점 |
| :--- | :--- |
| 동일 질환 특약 여러 개 | 월 보험료 합 vs 필요 목돈 |
| 부부 각자 | 가구 필요액·수익자 |
| 갱신형 진단 특약 | 보험료 상승(8화) |

필요 목돈은 **치료·휴직·고정비 N개월**처럼 가구가 정한 가정이 있어야 합니다.
가정 금액은 예시일 뿐, 여기서 상품을 권하지 않습니다.

## 5. 진단비와 수술·입원 일당

| 담보 | 지급 트리거 | 메모 |
| :--- | :--- | :--- |
| **진단비** | 약관상 진단 확정 등 | 목돈 |
| **수술비** | 약관 수술 분류 | 횟수·종류 |
| **입원일당** | 입원일수 | 단기 입원 트렌드와 괴리 가능 |

최근 의료 패턴상 단기 입원·통원이 늘면 입원일당만으로 부족할 수 있습니다.
**보유 담보의 트리거**만 정확히 알면, 불안 쇼핑을 줄일 수 있습니다.

## 이번 화 전략

**사회초년생**
- 부모님이 들어준 암 특약 정의부터 읽습니다.
- 금액보다 **무엇이 보장되는지**가 1순위입니다.

**맞벌이·부양 가구**
- 휴직 시 고정비 N개월을 가정해 필요 목돈을 적습니다.
- 부부 특약 합이 그 가정을 넘으면 중복 후보로만 표시합니다.

**가족력 불안**
- 불안만으로 특약을 늘리기 전에 **현재 정의 공백**이 있는지 약관으로 확인합니다.
- 공백이 없으면 “추가”가 아니라 **유지·보험료** 이슈입니다.

**갱신 부담이 큰 경우**
- 진단 특약의 갱신 보험료를 실손과 따로 적어 절감 순서를 정합니다.

## 확인 권장

- **금융감독원** — 보험금 청구·약관 해석 관련 안내
- **보험다모아** — 공시 참고(보유 특약 대체 아님)
- **보험사** — 특약 약관, 지급 사유 예시 안내
- **계약서·약관·진단서 요건** — 최종 기준

## 핵심 정리

1. 진단비는 이름보다 **약관상 질병 정의**가 전부입니다.
2. 실손(실비)과 진단비(정액 목돈)는 **역할이 다릅니다.**
3. 점검은 유행 특약 추가가 아니라 **보유 정의·금액·중복** 정리입니다.
