# 사망·종신·정기보험 | 보험점검 (5화)

안녕하세요.
안대표입니다.

사망 보장은 “있으면 안심”으로 남기기 쉽지만, 가구마다 **필요한 기간과 금액**이 다릅니다.
종신·정기·혼합형 특약을 구분하지 않으면, 저축·환급 목적과 보장 목적이 다시 섞입니다.
이번 화는 **이미 가입한 사망 관련 계약**을 기간·금액·수익자 관점으로 점검합니다.

## 30초 요약

- 사망 보장은 **유족 생활비·부채·장례 등**에 쓸 목돈이 목적일 때 의미가 큽니다.
- **정기**는 일정 기간, **종신**은 평생(계약 조건 내) — 보험료·환급 구조가 다릅니다.
- 점검은 상품 추천이 아니라 **필요 기간·필요 금액·수익자·중복** 확인입니다.

## Q. ‘종신이 무조건 좋다’는 말에 어떻게 답할까?

종신은 보장 기간이 길다는 장점이 있지만, 같은 가입금액이면 보험료 부담이 커지는 경우가 많습니다.
반대로 정기는 기간이 끝나면 보장이 사라집니다.
**좋은 상품**이 아니라 **지금 가구의 필요 기간**에 맞는지가 점검 기준입니다.

## 1. 유형만 먼저 태그

| 유형 | 핵심 | 점검 메모 |
| :--- | :--- | :--- |
| **정기** | 만기·갱신 기간 내 사망 시 | 만기 후 공백 |
| **종신** | 평생(약관·유지 조건) | 보험료·환급·특약 |
| **혼합·환급형** | 사망 + 적립·환급 | 2화 목적 분리 |
| **특약 사망** | 질병·상해 사망 특약 | 주계약과 중복 |

증권에 “종신”이어도 특약만 정기인 경우가 있습니다.
**주계약·특약별 만기**를 따로 적으세요.

## 2. 필요 금액 — 가정식으로만

여기서 제시하는 숫자는 **가정 예시**입니다. 개인 권고액이 아닙니다.

| 구성(가정) | 예시 질문 |
| :--- | :--- |
| **부채** | 주택담보·신용대출 잔액 |
| **생활비** | 배우자·자녀 연 생활비 × N년 |
| **일시** | 장례·정리 비용 |
| **차감** | 배우자 소득·예금·단체사망·이미 든 사망보험 |

> 필요액(가정) ≈ 부채 + 생활비 버퍼 − 대체 재원 − 기존 사망보장 합

표로 적어 두면 “막연히 더”가 줄어듭니다.
대체 재원에 예금을 넣는다고 해서 예금 해약을 권하는 것이 아닙니다.

## 3. 필요 기간

| 가구 상황 | 기간을 보는 관점 |
| :--- | :--- |
| **미성년 자녀** | 자녀 독립·학비 구간 |
| **주택담보** | 대출 잔존 기간 |
| **맞벌이** | 한쪽 소득 상실 시 회복 기간 |
| **부채 적음·자산 충분** | 사망보장 규모 축소 검토 여지 |

기간이 짧아졌는데 종신 고액만 남아 있으면 **감액·특약 정리** 후보가 됩니다.
반대로 기간이 남았는데 정기 만기가 임박하면 **공백** 후보입니다. (신규 가입 권유 아님)

## 4. 수익자·단체보험

| 항목 | 확인 |
| :--- | :--- |
| **수익자** | 배우자·자녀·상속 이슈 |
| **수익자 변경** | 이혼·재혼 후 미변경 |
| **직장 단체** | 사망·유족 특약 금액 |
| **대출 단체·신용생명** | 담보대출 연계 여부 |

개인 사망보험만 보고 단체·신용생명을 빼먹으면 **중복·과잉**으로 보일 수 있고,
단체만 믿으면 퇴직 시 **공백**이 생깁니다.

## 5. 환급·해지환급금에 끌릴 때

2화에서 말했듯, 환급형은 저축 목적과 섞이기 쉽습니다.

| 질문 | 점검 |
| :--- | :--- |
| 목적이 사망 보장인가 | 가입금액·기간만 보기 |
| 목적이 적립인가 | 사업비·해지환급·공시이율 |
| 둘 다인가 | 혼합으로 태그 후 분리 검토 |

“낸 돈이 아까워서”만으로 유지·해지를 정하지 말고, **보장 필요**와 **환급 기대**를 두 줄로 나누세요.

## 핵심 숫자·기준

| 항목 | 기준 | 비고 |
| :--- | :--- | :--- |
| **필요액** | 부채+생활 버퍼−대체재원(**가정**) | 권고액 아님 |
| **기간** | 부양·대출 **잔존 구간** | 가구마다 다름 |
| **정기 vs 종신** | **기간·보험료** 트레이드오프 | 우열 단정 금지 |
| **수익자** | 증권상 **지정** | 가족 변화 시 재확인 |
| **기준일** | **2026-07** | 약관·특약 우선 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 종신=무조건 정답 | **필요 기간**부터 |
| 가입금액만 키움 | 부채·생활비 **가정 표** |
| 수익자 방치 | 가족 변화 시 **변경** |
| 단체보험 무시 | 개인+단체 **합산** |
| 환급만 보고 유지 | 목적 **보장 vs 적립** 분리 |

## 실전 체크리스트

- [ ] 사망 관련 주계약·특약 **만기·가입금액** 표
- [ ] 필요 기간·필요액 **가정** 한 줄
- [ ] 단체·신용생명 포함 합산
- [ ] 수익자 지정 확인
- [ ] 환급형이면 2화 목적 태그 재확인

## 이번 화 전략

**미혼·부양 없음**
- 부채·장례 등 최소 필요만 가정해 과잉 여부를 봅니다.
- “나중에 필요할 테니 종신”은 이번 화 범위 밖입니다.

**자녀·주택담보 가구**
- 대출 잔액과 자녀 독립 시점을 기간의 앵커로 둡니다.
- 기존 정기 만기와 앵커가 어긋치면 공백·과잉만 표시합니다.

**외벌이**
- 소득원 상실 시 생활비 N년을 가정에 넣습니다.
- 배우자 소득·예금은 차감 항목으로만 기록합니다.

**은퇴 근접**
- 부양·대출이 줄었는지 다시 계산합니다.
- 종신 고액이 남아 있으면 감액·정리 후보로만 표시합니다.

## 확인 권장

- **금융감독원** — 보험 계약 조회, 약관 안내
- **보험다모아** — 공시 참고
- **보험사** — 가입금액, 만기, 해지환급금 예시, 수익자 변경
- **계약서·약관** — 지급 사유(질병·상해 사망 등)

## 핵심 정리

1. 사망 보장은 **필요 기간·필요 금액·수익자**로 점검합니다.
2. 정기와 종신은 우열이 아니라 **기간·비용 구조** 차이입니다.
3. 단체·신용생명을 합산해야 과잉·공백이 보입니다.
