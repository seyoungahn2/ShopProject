## Q. 해지와 감액·특약 정리의 차이는?

| 수단 | 결과 | 적합한 때 |
| :--- | :--- | :--- |
| **특약 삭제** | 해당 특약 보장·보험료 제거 | 중복·비필수 특약 |
| **감액** | 가입금액↓ → 보험료↓(통상) | 필요액이 줄어든 담보 |
| **해지** | 계약(또는 부분) 종료 | 더 이상 유지 이유 없음 |

가능 여부·최소 가입금액·심사 재개 여부는 **보험사·약관**마다 다릅니다.
앱에 버튼이 없으면 고객센터·설계 담당 경로를 확인합니다.

## 1. 신청 전 필수 확인 목록

| 확인 | 내용 |
| :--- | :--- |
| **대상 증권번호** | 동명 상품 혼동 방지 |
| **특약 코드·명칭** | 삭제·감액 단위 |
| **보장 종료 시점** | 신청일·승인일·자정 기준 |
| **해지환급금** | 예상액·지급 시기(해당 시) |
| **미납·연체** | 상계·효력 |
| **자동이체** | 해지 후 출금 여부 |
| **수익자·질권** | 대출 담보 설정 여부 |
| **단체·가족** | 종피보험자 영향 |

질권·대출 연계가 있으면 해지가 막히거나 동의 절차가 필요합니다.

## 2. 감액 시 체크

| 항목 | 질문 |
| :--- | :--- |
| **감액 후 가입금액** | 5화·4화 필요 가정과 맞는가 |
| **보험료 변화** | 견적·안내문 숫자 확인 |
| **특약 연동** | 주계약 감액 시 특약 자동 변화 |
| **재증액** | 나중에 올리려면 고지·심사인지 |

감액은 해지보다 되돌리기 쉽다고 단정할 수 없습니다.
**재가입·증액 시 조건**을 반드시 물어보세요.

## 3. 해지 시 체크

| 항목 | 질문 |
| :--- | :--- |
| **대체 보장** | 단체·다른 계약으로 공백 메움? |
| **실손 공백** | 청구 중·치료 중이면 특히 주의 |
| **면책 재진입** | 새로 들면 면책·감액기간 가능 — 권유 아님, 리스크만 |
| **환급 vs 보장** | 환급금 때문에 필수 해지하는지 |
| **청약철회·품질보증** | 신계약에만 해당하는 제도 — 기존 장기와 혼동 금지 |

치료·입원 중이거나 청구 예정인 담보를 해지하지 않도록 **일정**을 먼저 봅니다.

## 4. 실행 순서(실무)

1. 9화 순위표에서 **이번 달에 손댈 1~2건**만 고른다.  
2. 보험사에 **특약삭제/감액/해지 시 보험료·환급·보장종료일**을 서면·앱으로 받는다.  
3. 배우자 등 이해관계자와 공유한다.  
4. 신청 접수번호·화면을 저장한다.  
5. 다음 출금일·증권 반영을 확인한다.  
6. 1화 목록 표를 갱신한다.

한 번에 전부를 정리하려다 실수하기보다, **건수 제한**이 안전합니다.

## 5. 불성립·민원

안내와 다른 출금·보장이 남으면 보험사에 먼저 확인하고,
해결되지 않으면 **금융감독원 민원·조정** 경로를 안내받을 수 있습니다.
여기에서는 개별 사건 대리를 하지 않습니다.

## 이번 화 전략

**사회초년생**
- 앱으로 특약 삭제 가능한지부터 확인합니다.
- 해지환급이 거의 없는 순수보장도 공백만 보면 됩니다.

**부부 공동 가계**
- 신청 전 스크린샷을 공유합니다.
- 수익자·자동이체 명의를 같이 봅니다.

**치료·청구 경험자**
- 관련 담보 해지는 청구 종결·의사 일정 뒤로 미룹니다.
- 실손 공백이 생기지 않는지 이중 확인합니다.

**질권·대출 연계**
- 은행·보험사에 해지 가능 여부를 먼저 문의합니다.

## 확인 권장

- **금융감독원** — 해지·민원·계약 조회 안내
- **보험다모아** — 참고용
- **보험사 앱·고객센터·창구** — 감액·특약삭제·해지 절차
- **계약서·약관·질권 서류** — 제한 사유

## 핵심 정리

1. 특약 삭제·감액·해지는 **효과가 다른 수단**입니다.
2. 신청 전 **서면 수치·보장 종료일·공백**을 확인합니다.
3. 실행은 **소량씩**, 사후 증권·출금·목록 갱신까지가 한 세트입니다.
