# 왜 보험 점검이 필요한가 | 보험점검 (1화)

안녕하세요.
안대표입니다.

보험은 “가입하면 끝”이 아닙니다.
가족 구성, 소득, 집·차, 직장 단체보험이 바뀌어도 보험료는 매달 빠져나갑니다.
이번 시리즈는 **새 상품을 파는 글이 아니라**, 이미 가입한 계약을 **점검·정리·비교**하는 방법을 12화에 걸쳐 정리합니다.

## 30초 요약

- 보험 점검은 **가계 지출 절감**과 **필수 보장 유지**를 동시에 보는 일입니다.
- 초점은 특정 보험사·상품 추천이 아니라 **내 계약서·약관·보험료 고지서**입니다.
- 이 시리즈는 보장성·저축성 구분, 실손·진단비·자동차, 중복·갱신, 해지·감액 순서를 다룹니다.

보험을 “더 들어야 하나?”보다 먼저 물을 질문은 이것입니다.
**지금 내고 있는 보험료가, 지금 필요한 보장과 맞는가?**

---

## Q. 왜 ‘가입’보다 ‘점검’이 먼저일까?

많은 가계에서 보험은 월급에서 **고정비**처럼 나갑니다.
그런데 보장 내용은 가입 시점의 나이·가족·소득을 기준으로 짜여 있습니다.

이사가고, 아이가 생기고, 차가 바뀌고, 회사가 단체보험을 새로 들어도
개인 계약은 자동으로 맞춰지지 않습니다.
그래서 **점검 없이 추가 가입**하면 중복·과잉이 쌓이기 쉽습니다.

**점검은 해지가 목적이 아닙니다. 필요한 것은 남기고, 겹치거나 목적이 흐린 것을 정리하는 일입니다.**

## 1. 이 시리즈가 다루는 것

1. 보장성·저축성 **목적 구분**
2. 실손·진단비·사망·자동차 **계약 읽기**
3. 가족·단체보험까지 포함한 **중복 점검**
4. 갱신형 보험료 상승에 대비한 **부담 관리**
5. 보험료를 줄일 때의 **순서**(필수 유지 → 정리)
6. 해지·감액·특약 정리 **절차**
7. 비교견적·설계를 받을 때 **질문 리스트**
8. **연 1회** 점검 루틴

다루지 않는 것: 특정 보험사·상품 “이게 최고”, 수익률 보장, 가입 권유.

## 2. 점검이 필요한 네 가지 신호

| 신호 | 예시 | 점검 방향 |
| :--- | :--- | :--- |
| **지출 압박** | 보험료가 월급의 큰 비중 | 필수·비필수 구분 |
| **가족 변화** | 결혼·출산·독립·이혼 | 수익자·보장금액 |
| **보장 공백 불안** | “뭔가 부족한 것 같아” 추가 가입 | 계약 목록부터 |
| **갱신 고지** | 보험료가 눈에 띄게 오름 | 갱신형·실손 세대 |

불안만으로 설계서를 새로 받으면, 기존 계약과 **겹치는 특약**이 또 붙기 쉽습니다.
먼저 **보유 계약 목록**을 한 장으로 만드세요.

## 3. 점검의 범위 (시리즈 공통)

| 구분 | 포함 | 비고 |
| :--- | :--- | :--- |
| **보장성** | 실손, 진단비, 수술·입원, 사망, 운전자·자동차 | 가계 위험 대비 |
| **저축·투자성** | 연금저축성, 변액, 일부 종신 환급형 등 | 목적·수익률·수수료 별도 |
| **직장·단체** | 회사 단체상해·실손 특약 | 개인과 중복 여부 |
| **가족 합산** | 배우자·자녀 명의 계약 | 가구 단위로 보기 |

자동차보험은 “매년 갱신”이라 별도 리듬이 있습니다.
실손·장기보장성은 “오래 묵은 계약”일수록 약관·세대·갱신 주기를 다시 읽어야 합니다.

## 4. 한 장 목록부터 — 템플릿

아래 열만 채워도 이후 점검이 쉬워집니다.

| 열 | 적을 내용 |
| :--- | :--- |
| **보험사·상품명** | 증권·앱에 나온 이름 |
| **계약일·만기** | 가입·보장 종료 |
| **월 보험료** | 특약 포함 합계 |
| **주계약·특약** | 실손 / 암 / 뇌·심장 / 사망 등 |
| **갱신 여부** | 갱신형·비갱신형·주기 |
| **수익자** | 사망·진단 시 누구 |
| **메모** | 단체보험과 겹침 의심 등 |

금액은 **가정 예시**가 아니라 **내 고지서 숫자**를 넣습니다.
표가 없으면 실수·중복을 눈으로 못 봅니다.

## 5. 시리즈가 지키는 원칙

1. **계약서·약관이 최우선** — 블로그 요약보다 내 문구가 맞습니다.
2. **특정 상품 권유 없음** — “어떤 회사 몇 호”를 팔지 않습니다.
3. **필수 보장 유지** — 보험료만 줄이려다 꼭 필요한 담보를 지우지 않습니다.
4. **확인 창구** — 금융감독원, 보험다모아, 보험사 고객센터·앱을 안내합니다.

수치가 나오는 회차도 **2026-07 기준의 일반적 구조**를 설명합니다.
세대·자기부담·특약 이름은 가입 시점·상품마다 다르니, 최종 판단은 약관입니다.

## 핵심 숫자·기준 (시리즈 앵커)

| 항목 | 기준 | 비고 |
| :--- | :--- | :--- |
| **점검 단위** | **가구·계약 목록** | 명의가 달라도 합산 |
| **우선 자료** | **증권·약관·보험료 고지** | 설계서만으로 판단 금지 |
| **실손** | **비례보상** 구조가 일반적 | 중복 가입 ≠ 중복 수령 |
| **절감 원칙** | **필수 유지 → 중복·비필수 정리** | 해지 순서가 중요 |
| **수치 기준일** | **2026-07** | 상품·특약은 개인 약관 우선 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 불안해서 바로 추가 가입 | **보유 목록**부터 작성 |
| 설계사 말만 듣고 정리 | **약관·보장개시·면책** 확인 |
| 보험료만 보고 전면 해지 | **필수 담보** 먼저 표시 |
| 실손 여러 개 = 더 많이 받음 | 실손은 보통 **실제 의료비 한도 내 비례** |
| “환급되는 보험”만 고집 | 목적(보장 vs 저축)을 **분리** |

## 이번 화 전략

**사회초년생**
- 부모님이 들어준 계약이 남아 있는지부터 확인합니다.
- 새 설계보다 **목록·월 보험료**만 파악해도 1화 목표입니다.

**외벌이·맞벌이 가구**
- 배우자·자녀 계약을 **가구 합산표**로 만듭니다.
- 누가 얼마를 내는지와 수익자 지정만 맞춰도 구멍이 보입니다.

**자영업·프리랜서**
- 소득 변동이 크면 갱신형 부담이 더 크게 느껴집니다.
- 고정비로 묶인 보험료 합계를 **현금흐름 표**에 먼저 올립니다.

**중년·은퇴 준비**
- “예전 보험이 최고”라는 말보다 **지금 보험료·보장 종료 나이**를 봅니다.
- 환급·해지환급금에만 끌려 보장을 비우지 않도록 원칙만 적어 둡니다.

## 확인 권장

- **금융감독원** — 보험 계약 조회·민원·약관 이해 자료
- **보험다모아**(금융소비자 정보포털 계열 비교 공시) — 공시·비교 시 참고
- **보험사 앱·고객센터** — 증권 재발급, 특약 목록, 보험료 상세
- **내 계약서·약관** — 최종 기준. 블로그·유튜브 요약보다 우선

## 핵심 정리

1. 보험 점검은 판매가 아니라 **기존 계약을 목적에 맞게 재정렬**하는 일입니다.
2. 시작은 **가구 단위 계약 목록**과 월 보험료 합계입니다.
3. 이 시리즈는 필수 보장을 지키면서 **중복·목적 혼동·갱신 부담**을 줄이는 순서를 다룹니다.
