# 중복 보장 찾는 법 | 보험점검 (7화)

안녕하세요.
안대표입니다.

보험료가 부담될 때 가장 먼저 손대기 좋은 후보가 **중복**입니다.
다만 실손처럼 중복 수령이 안 되는 담보와, 진단비처럼 각각 지급되는 담보를 같은 방식으로 지우면 실수입니다.
이번 화는 **가족·단체보험까지 포함한 중복 맵**을 만드는 방법입니다.

## 30초 요약

- 중복은 “특약 이름이 같다”가 아니라 **같은 위험·같은 지급 사유**가 겹치는지를 봅니다.
- **실손형(실손)**과 **정액형(진단·일당 등)**의 중복 의미가 다릅니다.
- 개인 계약만 보지 말고 **배우자·자녀·직장 단체**를 한 표에 올립니다.

## Q. 이름이 다르면 중복이 아닌가?

“암수술비”와 “질병수술비”는 이름이 달라도 같은 수술을 두 번 보장할 수 있습니다.
반대로 이름은 비슷해도 약관 정의가 다르면 공백일 수 있습니다.
**약관 지급 사유**로 묶는 것이 안전합니다.

## 1. 중복 맵 템플릿

가구 단위로 아래 표를 만듭니다.

| 위험(열) | 계약A | 계약B | 단체 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **실손(의료비)** | O/X | O/X | O/X | 비례·중복 수령↓ |
| **암 진단** | 금액 | 금액 | 금액 | 정액 합산 가능 |
| **뇌·심장 진단** | | | | 정의 확인(4화) |
| **사망** | | | | 5화·신용생명 |
| **운전자·교통** | | | | 자동차·운전자 장기 |
| **배상책임** | | | | 일상생활·자동차 |

O/X와 금액만 채워도 “겹침 후보”가 드러납니다.
해지는 아직 하지 않습니다. **표시만** 합니다.

## 2. 실손형 vs 정액형

| 유형 | 중복 시 흔히 | 점검 행동 |
| :--- | :--- | :--- |
| **실손** | 보험료만 이중, 보상은 실손 한도 내 | 유지 필요성·단체 공백 |
| **정액** | 조건 충족 시 **각각** 지급 가능 | 필요 목돈 vs 합계 |
| **일당·수술** | 중복 지급 가능 | 실제 입원·수술 패턴 |

“중복=무조건 해지”가 아닙니다.
실손은 이중 납입 낭비가 크기 쉽고, 정액은 **필요액 초과**일 때 후보가 됩니다.

## 3. 가족·단체에서 놓치기 쉬운 곳

| 출처 | 확인할 것 |
| :--- | :--- |
| **배우자 명의** | 실손·진단·운전자 |
| **자녀** | 부모 실손 종피보험자 + 자녀 전용 |
| **직장 단체** | 실손·상해·사망·진단 특약 한도 |
| **신용카드·은행** | 무료 상해·여행 특약(범위 협소) |
| **자동차** | 자상·무보험차 vs 운전자보험 |

단체보험은 퇴직·휴직·계약 변경 시 사라질 수 있습니다.
개인 계약을 줄일 때 **단체 의존도**를 메모하세요.

## 4. ‘유사 중복’ 체크 질문

1. 같은 진단코드·수술에 **두 특약이 동시에** 해당하는가?  
2. 실손이 두 개인가, 정액이 두 개인가?  
3. 자동차와 운전자 장기에서 **변호사비·벌금·부상**이 겹치는가?  
4. 사망이 종신+정기+단체+신용생명으로 **합산 과잉**인가?  
5. 일상생활배상과 자동차 대물이 **사고 유형**에서 역할이 다른가?

5번은 이름이 비슷해도 적용 현장이 다릅니다.
겹친다고 단정하기 전에 **사고 유형**을 한 줄로 적습니다.

## 이번 화 전략

**맞벌이**
- 부부 실손·진단이 대칭으로 겹치는지 맵 한 장으로 봅니다.
- 한쪽 단체보험이 두꺼우면 개인 쪽 후보를 표시만 합니다.

**자녀 가구**
- 자녀가 여러 증권에 종피보험자로 들어가 있는지 확인합니다.
- 소아 실손·어린이보험 특약 이름을 지급 사유로 재분류합니다.

**이직·퇴직 예정**
- 단체 의존 담보에 형광펜을 칩니다.
- 퇴직 전 개인 공백 여부를 맵에 날짜와 함께 적습니다.

**다중 차량·운전자**
- 자동차·운전자 장기의 교통 관련 특약을 한 열에 모읍니다.
