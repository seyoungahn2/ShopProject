# 보험점검 시리즈 — 회차별 AI 이미지 프롬프트 (각 2개)

티스토리 본문 삽입용. 이미지 생성 AI(미드저니·DALL·E·이미지FX 등)에 **영문 프롬프트**를 넣고,  
한국어 설명은 배치·파일명 참고용입니다.

공통 네거티브(필요 시 추가):
`no text, no watermark, no logo, no emoji, no purple neon glow, no stock-photo handshake, no insurer brand marks`

스타일 공통 권장:
- 현실적·편집 사진/플랫 일러스트 중 택1을 시리즈 전체에서 통일
- 서류·체크리스트·가정 책상·약관 철의 느낌의 **점검 톤** (화려한 세일 배너 지양)

## 1화 — 왜 보험 점검이 필요한가

**배치 제안:** 서론 아래 / “가입보다 점검” 섹션

```
한국어: 증권 철과 가계부 노트가 쌓인 책상 — “보유 계약부터” 분위기.

### 프롬프트 B

```
한국어: 빈 체크리스트·계산기 탑뷰 — 시리즈 시작 “목록” 시각.
