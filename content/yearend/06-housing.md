안대표입니다.

주거비는 가계에서 가장 큰 고정비 중 하나입니다.
연말정산에서는 **월세 세액공제**, **전세·월세 보증금 관련**, **주택임차차입금·장기주택저당차입금** 등이 자주 등장합니다.
서로 **중복 선택이 막히는 조합**이 있어, “다 넣기”가 아니라 “맞는 칸 하나”가 핵심입니다.

## 30초 요약

- 무주택 근로자 등의 **월세 세액공제**는 소득·주택 규모·계약·송금 증빙이 핵심이다.
- 전세·대출이 있으면 **주택임차차입금 원리금** 또는 **장기주택저당차입금 이자** 소득공제 후보를 본다.
- 항목 간 **중복 적용 제한**이 있으니, 해당 과세연도 안내의 “함께 못 쓰는 조합”을 먼저 확인한다.

## 1. 주거 관련 공제 지도

| 유형 | 형태 감각 | 누구에게 자주 해당 |
| :--- | :--- | :--- |
| **월세 세액공제** | 세액공제 | 무주택·일정 소득 이하·월세 거주 |
| **주택임차차입금 원리금 상환** | 소득공제 | 전세·월세 보증금 마련 대출 등 |
| **장기주택저당차입금 이자** | 소득공제 | 주택 구입 담보대출 이자 |
| **월세 소득공제(사업자 등)** | 별도 트랙 | 근로 연말정산과 혼동 주의 |

이름은 비슷해도 **세액공제 vs 소득공제**가 다릅니다.
체감 환급액도 달라지니, 칸을 섞어 넣지 마세요.

## 2. 월세 세액공제 — 체크 포인트

흔한 요건 틀(세부 숫자는 **해당 과세연도** 확인):

- **무주택 세대 세대주** 또는 일정 요건의 세대원
- **총급여·종합소득**이 일정 금액 이하
- 주택 규모(전용면적 등) 요건
- **임대차계약서** 상의 입주자·주소
- 집주인 명의·실제 **월세 송금** 증빙 (이체내역)

현금으로만 주고 이체 흔적이 없으면 증빙이 약합니다.
가능하면 **계좌이체 + 계약서 주소 = 주민등록**을 맞춥니다.

세액공제율·한도는 소득 구간에 따라 **차등**되는 연도가 많습니다.
“월세 × 몇 %”를 작년 기억으로 고정하지 마세요.

## 3. 전세·보증금 대출 — 임차차입금

전세자금대출·보증금 대출의 **원리금 상환액**이 소득공제 대상이 되는 경우가 있습니다.
은행 납입증명·잔액증명과 함께, **무주택·주택 규모·세대주** 등 요건을 봅니다.

주의:

- 배우자·부모 명의 대출과 **누가 공제할지**
- 사채·개인 간 차용은 요건·증빙이 까다롭거나 제외될 수 있음
- 월세 세액공제와 **중복 제한** 여부

## 4. 주택 구입 — 장기주택저당차입금 이자

내 집 담보대출의 **이자** 상환액이 소득공제 후보입니다.
원금은 제외되고 이자만인 경우가 일반적입니다.
대출 시기·상환 기간·주택 수·세대주 요건이 붙습니다.

| 체크 | 내용 |
| :--- | :--- |
| 주택 수 | 1주택·일시적 2주택 등 예외 문구 확인 |
| 차입금 | 금융기관 주택담보대출인지 |
| 서류 | 이자상환증명서, 등기·계약 |
| 중복 | 월세·임차차입금 등과 동시 적용 제한 |

“이자 많이 냈다 = 공제 많이”도 한도에서 멈춥니다.
한도는 **해당 과세연도** 표를 따릅니다.

## 5. 중복·선택 — 한 줄 의사결정

실무에서는 이런 순서가 덜 헷갈립니다.

1. 올해 주거 형태: **월세 / 전세+대출 / 자가+주담대 / 혼합**
2. 홈택스·국세청의 **중복 불가 표** 확인
3. 가능한 칸이 둘이면, **가정 예시로 세액 효과** 비교 (세율 구간 고려)
4. 증빙이 약한 쪽은 과감히 포기하고 강한 쪽만 제출

효과가 애매하면 회사 연말정산 담당·세무 상담을 짧게라도 받는 편이, 잘못된 중복보다 낫습니다.

## 6. 가정 예시: 월세 vs 임차대출

**가정 예시** (한도·공제율은 홈택스 수치로 치환)

| 시나리오 | 선택 후보 | 증빙 |
| :--- | :--- | :--- |
| 무주택·월세·소득 요건 충족 | **월세 세액공제** | 계약서·이체·등본 |
| 전세자금대출 원리금 상환 중 | **임차차입금 소득공제** | 은행 증명 |
| 둘 다 해당처럼 보임 | **중복 안내 확인 후 1선택** | — |

세액공제 100만과 소득공제 100만은 다릅니다.
과세표준 구간에 따라 유불리가 갈리니, **결정세액 미리보기**(간소화 후)로 비교하는 것이 안전합니다.

## 7. 놓치기 쉬운 실무

- 계약자만 배우자이고 송금은 나 → 명의·세대 요건 재확인
- 연중 이사로 주소·계약이 여러 건 → **기간별** 안분·해당분만
- 고시원·기숙사·사택 → 대상 주택·계약 형태인지 확인
- 전대차·불법 계약 → 공제 리스크, 제도 취지와 무관하게 위험
- 오피스텔 주거용 → 주택 요건·현황 자료

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 월세·임차대출·주담대 이자 동시 올인 | **중복 불가**부터 확인하고 1~조합만 |
| 현금 월세만 내고 이체 없음 | **이체 증빙** 남기기 |

| 배우자 계약·내 송금 방치 | 명의·세대주·실제 거주 일치 |
| 한도를 무한정으로 기대 | 연간 한도·공제율 **표 확인** |

## 실전 체크리스트

- [ ] 올해 주거 형태(월세/전세/자가)와 대출 유무를 한 줄로 적었다
- [ ] 월세라면 계약서·등본·**이체내역**을 파일로 묶었다
- [ ] 전세·주담대라면 은행 **상환증명**을 발급받았다
- [ ] 무주택·소득·면적 요건을 해당 연도 안내와 대조했다
- [ ] 중복 불가 조합을 읽고 **선택지**를 정했다
- [ ] 맞벌이라면 누가 공제할지 합의했다
- [ ] 최종 숫자는 **홈택스 미리보기**로 검증한다고 표시했다

## 이번 화 전략

**사회초년·월세**: 이체 증빙과 계약서만 완벽하게 준비해도 절반이다. 공제율은 홈택스에서 본 뒤 기대 환급을 조정한다.

**전세 대출 가구**: 월세 칸이 비어도 **임차차입금**이 열려 있는지 본다. 원리금 증명서 발급일을 회사 마감에 맞춘다.

**자가·주담대**: 이자 증명만 챙기고, 월세·임차와 중복되지 않는지 확인한다. 2주택 이슈가 있으면 문구를 더 읽는다.

## 확인 권장

- **국세청·홈택스**: 월세·주택자금 공제 요건·중복·한도
- **주민센터**: 주민등록등본·초본
- **금융기관**: 원리금·이자 상환증명
- **임대인·공인중개사**: 계약서 원본·확정일자(해당 시)

## 핵심 정리

1. 주거 공제는 **월세 세액 / 임차 원리금 / 주담대 이자**를 지도로 나눈다.
2. **중복 제한**이 있으므로 다 넣지 말고 선택한다.
3. 계약·이체·등본·은행 증명이 **같은 이야기**를 해야 한다.
