오늘은 대상·한도·증빙만 실무적으로 정리합니다.

## 1. 보장성 vs 저축성 — 먼저 선 긋기

| 구분 | 연말정산 감각 | 비고 |
| :--- | :--- | :--- |
| **보장성** | 위험 보장 목적 보험료가 세액공제 후보 | 생명·손해 보장성 등 |
| **저축성·투자형** | 공제 대상에서 빠지거나 별도 취급인 경우 많음 | “보험” 이름만으로 판단 금지 |
| **연금저축·IRP** | **연금 세액공제** 트랙 (보험료 공제와 별개) | 연금 세액공제 트랙(별도) |
| **ISA** | 가입·납입만으로 연말정산 보험/세액공제 없음 | 역할 분리 |

공제를 노리고 보험을 더 드는 것은 순서가 반대입니다.
**필요한 보장**을 정한 뒤, 이미 낸 보험료가 공제 후보인지 확인하는 편이 맞습니다.

## 2. 세액공제 구조 (흔히 쓰는 틀)

과세연도마다 숫자가 달라질 수 있어, 여기서는 **틀**만 적습니다.
실제 한도·공제율은 **해당 과세연도 홈택스**를 보세요.

흔히 안내되는 감각:

- 공제 대상 보험료에 대해 **일정 공제율**(예: 일반·장애인 차등) 적용
- **연간 한도**가 있어, 보험료를 많이 내도 한도에서 멈춤
- **지방소득세**까지 포함한 체감은 안내문 기준으로 재계산

**가정 예시**: 공제 대상 보험료가 한도를 채웠다면, 세액공제액은 `한도 × 공제율` 근처로 감이 잡힙니다.
한도를 넘긴 보험료는 “보장은 되지만 공제는 더 이상”인 경우가 많습니다.

## 3. 누구의 보험료인가

핵심 질문 세 가지입니다.

1. **계약자·피보험자·수익자** 구성이 공제 요건과 맞는가
2. 피보험자(또는 요건상 가족)가 **나의 인적공제 대상**인가
3. 납입 증빙이 **나의 연말정산**에 붙는가 (간소화 귀속)

부모님 보험을 내가 내고 있어도, 인적공제 대상이 아니거나 명의·요건이 안 맞으면 공제가 안 될 수 있습니다.
3화에서 만든 **부양 맵**과 보험 계약을 한 줄로 잇습니다.

## 4. 실손·자동차·단체 — 자주 헷갈리는 것

| 유형 | 체크 포인트 |
| :--- | :--- |
| **실손의료보험** | 보장성으로 포함되는 경우가 많으나, **간소화 반영·특약** 확인 |
| **자동차보험** | 개인 보장성으로 보는 범위·특약 구성을 약관·안내로 확인 |
| **직장 단체보험** | 회사가 부담하는 부분과 개인 부담 분리 |
| **운전자·여행자** | 단기·특약은 간소화 누락·제외 가능 — 보험사 문의 |
| **화재·배상** | 보장 목적·계약 주체(개인/사업)에 따라 갈림 |

“보험료 냈으니 다 들어간다”가 아닙니다.
홈택스 간소화에 나온 금액을 **계약별로 대조**하고, 빠진 것은 납입증명서를 받습니다.

## 5. 한도와 우선순위

보험료 세액공제 한도는 **상대적으로 작은 편**으로 느끼는 사람이 많습니다.
그래서 전략은 단순합니다.

1. 이미 가입한 보장성 중 **공제 대상만** 정확히 올린다
2. 한도를 채웠다면, 추가 가입을 공제 때문에 늘리지 않는다
3. 여유 자금의 절세는 **연금·IRP·카드 사용 구조** 등과 비교한다 (각각의 한도·요건 확인)

공제액보다 **보장이 중복**이면, 보험 점검(해지·감액)이 가계에 더 이득일 수 있습니다.
공제와 보장은 목적을 섞지 않습니다.

## 6. 간소화에 없을 때

- 보험사 고객센터에서 **연말정산용 납입증명** 발급
- 계약자 주민번호·납입 기간(해당 과세연도) 확인
- 회사에 PDF·이미지 제출 형식 확인
- 맞벌이라면 **어느 배우자 간소화에 붙는지** 사전 합의

경정·수정이 필요하면 홈택스 기한 안내를 따릅니다.

## 7. 보험료와 의료비·실손 정산

실손으로 의료비를 보전받으면, **의료비 세액공제** 쪽에서 차감·조정이 생기는 구조가 있습니다.
보험료 공제와 의료비 공제는 다른 칸이지만, **실손 수령액**이 의료비 계산에 영향을 줍니다.
의료비 공제는 별도로 다루고, 여기서는 “실손 청구 내역을 연말에 모아 둔다” 정도만 기억하면 됩니다.

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 모든 보험료를 공제 입력 | **보장성·요건·명의**만 선별 |
| 공제 한도 채우려고 신규 가입 | 보장 필요성 먼저, 공제는 부수 |
| 인적공제 안 되는 가족 보험료 기대 | 부양 맵과 **계약 피보험자** 일치 확인 |
| 간소화 숫자만 믿고 계약 미대조 | 보험사 증명과 **항목별** 대조 |
| 연금저축을 보험료 공제란에 혼동 | **연금 세액공제** 란으로 분리 |

## 실전 체크리스트

- [ ] 보유 계약을 **보장성/저축성/연금**으로 분류했다
- [ ] 피보험자가 **인적공제 대상**인지 표로 맞췄다
- [ ] 홈택스 간소화 보험료와 보험사 납입내역을 대조했다
- [ ] 누락 계약은 **납입증명서**를 발급받았다
- [ ] 단체보험·자동차·실손의 포함 여부를 안내문으로 확인했다
- [ ] 공제 한도를 채운 뒤 **추가 가입을 공제 목적으로 하지 않기로** 정했다
- [ ] 실손 수령 내역을 의료비 공제용으로 모아 둘 폴더를 만들었다

## 이번 화 전략

**초보**: 간소화에 찍힌 보장성만 넣고, 애매한 특약은 보험사에 “연말정산 대상 여부”를 한 줄로 묻는다.

**직장인**: 한도 근처인지 먼저 본다. 이미 한도라면 공제 최적화보다 **중복 보장 정리**가 이득일 수 있다.

**부부**: 가족 보험을 한쪽에 몰 때, **인적공제 담당과 동일인**인지 확인한다. 어긋나면 공제가 공중에 뜹니다.

- **보험사·보험다모아(참고)**: 납입증명, 상품 유형(보장/저축)
- **회사 급여팀**: 제출 형식·마감

## 핵심 정리

1. 연말정산 보험료는 **보장성 세액공제**가 중심이고, 한도·공제율은 홈택스 확인이 필수다.
2. **인적공제 대상·계약 명의**가 맞아야 공제가 살아난다.
3. 공제 때문에 보험을 늘리지 말고, **이미 낸 보험료의 정확한 반영**이 목표다.
