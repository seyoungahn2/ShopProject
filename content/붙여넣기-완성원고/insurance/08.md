# 갱신형 vs 비갱신형 | 보험점검 (8화)

안녕하세요.
안대표입니다.

보험료가 “지금은 괜찮은데” 하다가, 갱신 고지에서 크게 오르는 경우가 있습니다.
실손·일부 진단·운전자 특약이 갱신형인 경우가 많고, 비갱신형은 초기에 더 비싸 보여도 **연령 상승분**이 다르게 움직입니다.
이번 화는 상품 추천이 아니라 **보유 계약의 갱신 구조와 보험료 경로**를 읽는 법입니다.

## 30초 요약

- **갱신형**은 주기마다 보험료가 재산정될 수 있고, **비갱신형**은 만기까지 보험료가 고정되는 구조가 일반적입니다(특약·상품별 예외 가능).
- 점검은 “어느 쪽이 이득”보다 **내 계약이 어떤지·최근 고지 추이**입니다.
- 상승이 가파르면 절감 순서·감액·특약 정리 후보로 연결합니다.

## Q. 갱신형이 ‘나쁜’ 보험인가?

아닙니다.
초기에 보험료가 낮아 진입이 쉬운 면도 있고, 실손처럼 구조상 갱신이 흔한 영역도 있습니다.
문제는 갱신 여부를 **모른 채** 장기 고정비로만 인식하는 것입니다.

## 1. 한눈에 보는 차이(일반론)

| 구분 | 보험료 | 점검 포인트 |
| :--- | :--- | :--- |
| **갱신형** | 갱신 때 재산정 가능 | 주기·연령·손해율·고지 |
| **비갱신형** | 만기까지 동일 설계가 흔함 | 초기 수준·납입 기간 |
| **혼합** | 특약별 상이 | 특약마다 표시 |

증권·청약서에 “갱신형/비갱신형”, “갱신주기 1년” 등이 있습니다.
없으면 보험사에 **특약별**로 물어 표에 적습니다.

## 2. 보유 계약 기록표

| 특약 | 갱신 | 주기 | 최근 3회 보험료 | 메모 |
| :--- | :--- | :--- | :--- | :--- |
| 실손 | | | | 3화 |
| 암 진단 | | | | |
| 뇌·심장 | | | | |
| 운전자 | | | | |
| 기타 | | | | |

“전체 월 보험료”만 보면 어떤 특약이 올랐는지 모릅니다.
**특약별 고지**가 핵심입니다.

## 3. 왜 오를 수 있나(개념)

| 요인 | 설명(개념) |
| :--- | :--- |
| **연령** | 같은 위험도라도 나이 구간 상향 |
| **위험률·손해율** | 상품군·세대 구조에 따른 조정 |
| **특약 구조** | 비급여·할인할증 등(해당 시) |
| **가입금액** | 감액 없이 유지 시 부담 누적 |

미래 보험료를 여기서 예측·보장하지 않습니다.
다만 **과거 고지 3회**만 있어도 “완만 vs 가파름”은 구분됩니다.

## 4. 비갱신형을 볼 때

| 볼 점 | 이유 |
| :--- | :--- |
| **납입 기간** | 전기납·단기납 등 |
| **보장 만기** | 납입 종료 후 보장 유지 여부 |
| **초기 보험료** | 갱신형 초기와 단순 비교 금지 |
| **해지환급** | 저축 목적과 혼동 주의(2화) |

“비갱신이니까 무조건 유지”도 단정하지 않습니다.
목적이 사라진 특약이면 갱신 여부와 별개로 정리 후보입니다.

## 5. 상승 부담이 클 때의 선택지(개요)

상세 순서·절차는 감액·특약 삭제·해지 메뉴를 계약서에서 확인하세요. 여기서는 **메뉴만** 둡니다.

| 선택지 | 전제 |
| :--- | :--- |
| **유지** | 필수·대체 없음 |
| **감액** | 가입금액 축소로 보험료↓ |
| **특약 삭제** | 중복·비필수 |
| **전환·재가입** | 공백·인수·약관 차이 리스크 — 신중 |
| **해지** | 최후 순위에 가깝게 |

전환·재가입을 권하지 않습니다.
공백·면책·유사암 정의 차이 등 **약관이 바뀌는 리스크**만 인지하세요.

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 월 합계만 보고 놀람 | **특약별** 분해 |
| 갱신형=즉시 해지 | 필수·중복·추이 후 판단 |
| 비갱신=평생 안심 | **만기·납입·목적** 확인 |
| 미래 보험료 단정 | **과거 고지**만 기록 |
| 갈아타기부터 | 공백·약관 차이 **리스크** 인지 |

## 이번 화 전략

**사회초년생**
- 초기 저렴한 갱신형 특약의 **주기**만 알아도 성공입니다.
- 고지서를 이메일·앱에 모아 두는 습관을 만듭니다.

**40대 이후**
- 연령 상승과 맞물린 갱신 고지를 특약별로 분해합니다.
- 실손과 진단 특약을 한 줄에 섞지 않습니다.

**소득 변동 가구**
- 갱신 상승분을 **고정비 표**에 별도 행으로 올립니다.
- 필수만 남길 후보를 미리 표시합니다.

**은퇴 준비**
- 납입이 남은 비갱신과, 갱신으로 계속 오르는 특약을 분리해 현금흐름을 봅니다.

## 확인 권장

- **금융감독원** — 보험료·약관 관련 안내
- **보험다모아** — 공시 참고
- **보험사** — 특약별 갱신 여부, 과거·예정 고지 설명
- **보험료 고지서·약관** — 최종 기준

## 핵심 정리

1. 갱신형·비갱신형은 우열이 아니라 **보험료 경로**의 차이입니다.
2. 반드시 **특약별**로 주기와 고지 추이를 기록합니다.
3. 상승 부담은 해지부터가 아니라 **필수·중복·감액 순서**로 넘깁니다.
