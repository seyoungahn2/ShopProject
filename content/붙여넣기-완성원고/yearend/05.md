# 의료비·교육비 공제 | 연말정산 (5화)

안녕하세요.
안대표입니다.

병원비·학비를 많이 썼는데 환급이 기대보다 적은 경우가 있습니다.
의료비·교육비는 **최저 사용 기준·한도·실손 차감·인적공제 연동**이 겹칩니다.
오늘은 증빙과 계산 틀만 짚어, 기대치를 현실에 맞춥니다.

## 30초 요약

- 의료비는 흔히 **총급여의 일정 비율을 넘는 금액**부터 세액공제 후보가 되고, 실손 수령액은 차감되는 구조가 많다.
- 교육비는 **본인·취학 자녀 등 대상·학교급·한도**가 나뉘며, 학원비 포함 여부는 요건을 본다.
- 둘 다 **인적공제 대상 여부**와 간소화 누락(현금·해외·미등록)을 먼저 점검한다.

## 1. 의료비 세액공제 — 큰 그림

의료비는 보통 **세액공제**로 처리됩니다.
흔한 틀은 다음과 같습니다. (비율·한도·공제율은 **해당 과세연도** 확인)

1. 그해 지출한 **공제 대상 의료비** 합계
2. − **실손의료보험금 등** 보전받은 금액
3. − **총급여 × 일정 비율**(흔히 3%대로 안내되는 구간)에 해당하는 **최저 사용액**
4. 남는 금액 × **공제율** (난임·장애인·건강보험산정특례 등은 우대 구간이 있을 수 있음)
5. **한도**가 있는 유형과 없는(또는 다른) 유형을 안내문대로 구분

즉, “병원비 500만”이 곧 “세액공제 500만”이 아닙니다.
총급여가 높을수록 최저 사용액이 커져, 같은 병원비라도 공제가 작아질 수 있습니다.

## 2. 무엇이 의료비에 들어가나

| 포함 후보 (요지) | 주의 |
| :--- | :--- |
| 진료비·치료비·약제비 | 미용·건강기능식품 등과 구분 |
| 시력보정용 안경·콘택트 (한도 있는 경우) | **본인 등 요건·연간 한도** 확인 |
| 장애인 보장구·보청기 등 | 증빙·대상자 |
| 산후조리원 (요건·한도 있는 연도) | 해당 연도 문구 필수 |
| 노인장기요양 본인부담금 등 | 간소화·별도 증명 |

미용 목적 시술, 건강식품, 미용 안경은 빠지는 경우가 많습니다.
애매하면 **국세청 질의·홈택스 항목 설명**을 기준으로 합니다.

## 3. 실손과의 관계

실손으로 돌려받은 금액은 의료비 공제에서 **빼는** 쪽으로 이해하는 것이 안전합니다.
청구 중이거나 연도에 걸쳐 수령하면, **수령 연도·지출 연도** 매칭을 서류로 남겨 둡니다.

체크리스트:

- 실손 보험금 입금 내역(연도별)
- 병원·약국 영수증과 매칭
- 간소화의 “실손의료보험금” 란과 대조

4화에서 말한 보장성 **보험료** 공제와는 칸이 다릅니다.
보험료는 낸 돈, 의료비는 병원비(보전 후)입니다.

## 4. 교육비 세액공제 — 큰 그림

교육비도 흔히 **세액공제**입니다.
대상은 대략

- **근로자 본인** 교육비
- **취학 중인 자녀·인적공제 대상** 등 (관계·나이·학교 요건)

으로 나뉘고, **초·중·고 / 대학 / 유치원·어린이집** 등에 따라 한도가 다릅니다.
학원비·교복·체험학습비 포함 여부는 **학교급·항목**마다 다르니, “학원비 = 무조건”으로 단정하지 마세요.

| 구분 (감각) | 실무 포인트 |
| :--- | :--- |
| 본인 | 대학원·직업능력개발 등 범위 확인 |
| 취학 자녀 | 학교 납입금 위주, 학원 포함 여부 확인 |
| 장애인 특수교육 | 별도 한도·대상 안내 |
| 해외교육 | 증빙·환율·요건이 까다로움 — 사전 확인 |

## 5. 가정 예시: 의료비가 ‘안 먹는’ 이유

**가정 예시** (비율은 흔히 쓰이는 틀, 실제는 홈택스)

| 항목 | 금액 감각 |
| :--- | :--- |
| 총급여 | 5,000만 원 |
| 최저 사용 (예: 3%) | **150만 원** |
| 병원·약국 합계 | 200만 원 |
| 실손 수령 | 80만 원 |
| 공제 후보 기초 | 200 − 80 = 120만 |
| 최저 차감 후 | 120 − 150 = **음수 → 공제 0에 가까움** |

병원비를 냈다는 사실과 공제 발생은 별개입니다.
고액 수술·장기 치료가 아니면 의료비 공제가 작거나 없는 해가 흔합니다.

## 6. 증빙 — 간소화 밖을 찾는 법

간소화에 잘 안 뜨거나 누락되기 쉬운 것:

- 현금 진료, 미청구 영수증
- 안경·보청기 구매 영수증 (한도·대상 확인)
- 일부 비급여·별도 기관
- 해외 의료·교육
- 학교 외 교육비 중 요건 충족분

준비물 감각:

- 진료비 납입확인서, 약제비 영수증
- 교육비납입증명서, 입학금·수업료 영수증
- 인적공제 대상자 명의와 **지출자** 관계 설명 자료

회사 제출 전에 **본인 홈택스에서 미리보기**를 하면 누락을 일찍 발견합니다.

## 7. 맞벌이·부양과의 연결

의료비·교육비는 **내가 기본공제하는 가족** 지출이어야 하는 경우가 많습니다.
형제가 부모님 기본공제를 가져가면, 내가 낸 부모님 병원비가 내 공제에 안 붙을 수 있습니다.

전략:

1. 3화 부양 맵 확정
2. 그해 예상 의료·교육 지출이 큰 사람을 누가 공제할지 재검토
3. 중복·공중 부양(아무도 안 올림) 방지

## 실전 체크리스트

- [ ] 총급여를 기준으로 의료비 **최저 사용액**을 대략 계산해 봤다
- [ ] 실손·기타 보험금 수령 목록을 연도별로 모았다
- [ ] 간소화 의료비·교육비와 영수증을 대조했다
- [ ] 안경·교복·학원 등 경계 항목은 안내문으로 포함 여부를 확인했다
- [ ] 지출 대상자가 **내 인적공제 대상**인지 표로 맞췄다
- [ ] 맞벌이·형제와 부양·의료비 귀속을 합의했다
- [ ] 한도·공제율은 **해당 과세연도 홈택스**에 재확인한다고 메모했다

## 이번 화 전략

**초보**: 의료비는 “이번 해에 큰 수술·입원이 있었는가”만 먼저 본다. 일상 감기·실손 처리분만으로는 공제가 안 나는 해가 많다.

**직장인 부모**: 부모님 병원비가 크면 **기본공제 담당**을 의료비와 같은 쪽으로 맞출지 가족회의로 정한다.

**자녀 교육비 큰 가구**: 학교 납입증명부터 채우고, 학원·교복은 요건 확인 후 추가한다. 한도 안에서만 의미가 있다.

## 확인 권장

- **국세청·홈택스**: 의료비·교육비 세액공제 요건, 간소화
- **보험사**: 실손 지급내역
- **학교·유치원·학원**: 교육비납입증명서
- **건강보험공단·병원**: 진료비 납입확인

## 핵심 정리

1. 의료비는 **최저 사용·실손 차감·한도** 후의 세액공제다.
2. 교육비는 **대상·학교급·한도**를 나눠 보고, 학원비는 단정하지 않는다.
3. 인적공제 귀속이 어긋나면 지출이 커도 공제가 공중에 뜬다.
