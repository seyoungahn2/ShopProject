안녕하세요.
안대표입니다.

연말정산은 1월의 사건이 아니라 **연간 루틴**입니다.
지금까지의 화를 한 장 치트시트와 월별 할 일로 묶습니다.
숫자·한도는 기억하지 말고, **확인 습관**만 남기면 됩니다.

## 30초 요약

- 치트시트: **인적 → 주거 → 소비 → 보험·의료·교육 → 연금 → 기타 감면** 순으로 해당 여부만 체크한다.

- ISA 가입만으로 연말정산 세액공제는 없다 — 연금·IRP와 역할을 분리한다.

## 3. 월별 캘린더

### 1~2월 — 정산 시즌

- [ ] 간소화 조회·부양 동의
- [ ] 누락 증빙 첨부·회사 제출
- [ ] 미리보기 → 제출 → 원천징수영수증 확인
- [ ] 이상 시 회사 수정·경정 경로 확인

### 3~5월 — 보완

- [ ] 필요 시 경정청구·종합소득 신고
- [ ] 전년도 영수증·기부 폴더 아카이브
- [ ] 부양·혼인·이사 변동을 메모

### 6~8월 — 연중 유지

- [ ] 현금영수증·체크 비중 점검 (최저·한도 가늠)
- [ ] 월세 이체·계약 유지 확인
- [ ] 연금·IRP 자동이체 정상 여부
- [ ] ISA는 투자 일정만 (연말정산 공제로 착각 금지)

### 9~10월 — 예비 점검

- [ ] 총급여 누적으로 연금 공제율 구간 가늠
- [ ] 의료·교육 큰 지출 영수증 정리
- [ ] 기부금 폴더 중간 점검
- [ ] 중소기업 감면·우리사주 서류 상태

### 11~12월 — 한도 마감

- [ ] 연금·IRP **세액공제 한도** 잔여 납입 (금융사 마감 여유)
- [ ] 카드·현금 **한도·최저** 확인 후 불필요 소비 금지
- [ ] 기부·월세 증빙 최종 보완
- [ ] 회사 연말정산 일정 캘린더 등록
- [ ] ISA 납입은 공제와 무관하게 결정

## 5. 가계 현금흐름과 연결

연말정산을 “환급 이벤트”로만 보면 12월에 돈이 묶입니다.
가계 관점 우선순위 감각:

1. 고금리 부채 상환
2. 비상금
3. 연금·IRP **공제 한도 내** (중도인출 안 할 돈)
4. ISA·장기 투자
5. 소비성 “공제용” 지출 — **최후열**

카드 공제를 위해 쓰는 돈은, 공제 효과보다 지출이 큰 경우가 많습니다.

## 이번 화 전략

**초보**: 치트시트 1→10 순서대로 “해당/비해당”만 표시한다. 해당만 과거 화를 다시 읽는다.

**직장인**: 11~12월 연금 한도와 1~2월 홈택스만 캘린더에 고정한다. 나머지는 월 30분 루틴.

**부부**: 부양·월세·기부 담당을 나눠 치트시트에 이름을 쓴다. 중복 금지와 증빙 폴더를 공유한다.

## 확인 권장

- **국세청·홈택스**: 해당 과세연도 공제 요건·한도·간소화
- **금융회사**: 연금·IRP·ISA 한도·증명
- **회사 인사팀**: 제출 일정·감면 서류

## 핵심 정리

1. 연말정산은 **연간 체크리스트**로 굴리고, 숫자는 매년 홈택스에서 갈아끼운다.
2. 우선순위는 부채·비상금 다음 **연금 한도**, ISA는 별 트랙이다.
3. 환급·추가납부는 결과일 뿐, **기납부 vs 결정세액**을 영수증으로 검증한다.
