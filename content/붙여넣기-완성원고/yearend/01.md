# 연말정산이란, 환급 vs 추가납부 | 연말정산 (1화)

안녕하세요.
안대표입니다.

연말정산은 “세금이 새로 생기는 날”이 아니라, **이미 걷힌 세금과 실제 내야 할 세금을 맞추는 정산**입니다.
환급이 나오면 기쁘고 추가납부가 나오면 당황하기 쉽지만, 둘 다 같은 구조에서 나옵니다.
오늘은 그 구조를 한 장으로 잡고, 무엇을 준비해야 하는지만 정리합니다.

## 30초 요약

- 연말정산은 **원천징수세액 vs 결정세액**을 비교해 환급·추가납부를 정하는 절차다.
- 환급은 “보너스”가 아니라 **미리 더 낸 세금의 반환**, 추가납부는 **덜 낸 세금의 정산**이다.
- 공제·감면은 **해당 과세연도 요건·한도**를 홈택스에서 확인하고, 서류·간소화 자료를 맞춰야 한다.

## 1. 연말정산이 하는 일

직장인이면 매달 급여에서 **근로소득세·지방소득세**가 원천징수됩니다.
회사는 간이세액표 등을 기준으로 “대략 이만큼”을 떼고, 연말에 **실제 공제·감면**을 반영해 다시 계산합니다.

그 결과가

- **환급**: 미리 낸 세금 > 최종 결정세액
- **추가납부(징수)**: 미리 낸 세금 < 최종 결정세액

입니다.

프리랜서·사업소득자는 보통 **종합소득세 신고**로 비슷한 정산을 합니다.
이 시리즈는 주로 **근로소득 연말정산**을 기준으로 하고, 겹치는 공제(연금·기부 등)는 해당 화에서 짚습니다.

**한 줄로 말하면**: 연말정산은 “세금을 깎아주는 이벤트”가 아니라 **정산서**입니다.

## 2. 결정세액이 나오는 뼈대

흐름을 단순화하면 대략 이렇습니다.

1. **총급여** (비과세 제외 등 조정 후)
2. − **근로소득공제** → 근로소득금액
3. − **인적공제·특별소득공제·그 밖의 소득공제** → 과세표준
4. × **기본세율** → 산출세액
5. − **세액감면·세액공제** → **결정세액**
6. 결정세액 − **기납부세액(원천징수 합계)** → 환급 또는 추가납부

소득공제는 **과세표준을 줄이고**, 세액공제는 **세금 자체를 직접 깎습니다.**
같은 “100만 원 공제”라도 체감이 다릅니다.
예를 들어 과세표준이 중간 구간에 있는 가정 예시라면, 소득공제 100만 원의 세금 효과는 세율만큼이고, 세액공제 100만 원은 세금이 100만 원 줄어듭니다.
(실제 구간·세율·지방세는 **해당 과세연도** 확인.)

## 3. 환급이 많이 나오는 사람, 추가납부가 나오는 사람

환급이 큰 경우는 흔히 이런 패턴입니다.

- 부양가족·장애인 등 **인적공제**가 반영됐다
- 월세·주택자금·보험·의료·교육·기부 등 **특별공제·세액공제**가 크다
- 연금저축·IRP 납입으로 **세액공제**를 받았다
- 중도입사·무급휴직 등으로 **원천징수가 상대적으로 많았다**

추가납부가 나오는 경우는 반대입니다.

- 부양가족을 넣었는데 **중복·요건 미달**로 빠졌다
- 카드·의료 등 공제 기대가 컸는데 **한도·최저사용액**에 막혔다
- 이직·겸업으로 **원천징수가 부족**했다
- 중도퇴사 후 정산이 꼬였다

환급이 목표처럼 보이지만, 본질은 **정확한 정산**입니다.
덜 낸 것을 나중에 한꺼번에 내는 것보다, 매달·연중 공제를 맞춰 두는 편이 현금흐름에 유리합니다.

## 4. 회사에서 하는 일 vs 내가 하는 일

| 구분 | 회사(원천징수의무자) | 근로자 |
| :--- | :--- | :--- |
| 연중 | 급여 원천징수, 간이세액 적용 | 부양·공제 변동 시 회사에 알림 |
| 연말~초 | 간소화·서류 취합, 전산 제출 | **간소화 PDF·누락 서류** 확인·제출 |
| 결과 | 원천징수영수증·환급/추가징수 | 금액·공제 항목 **이상 여부** 점검 |

간소화서비스에 안 뜨는 항목(월세 계약서, 일부 기부, 외국 교육비 등)은 **직접 증빙**이 필요합니다.
“회사에 맡겼으니 끝”이 아니라, **내 서류가 빠지지 않았는지**가 환급·추가납부를 가릅니다.

## 5. ISA·연금·카드 — 역할을 섞지 말 것

절세 이야기가 나오면 계좌와 공제가 한 바구니에 섞입니다.
역할을 나누면 헷갈림이 줄어듭니다.

| 도구 | 연말정산과의 관계 (요지) |
| :--- | :--- |
| **연금저축·IRP** | 납입액에 대해 **세액공제**가 붙는 경우가 많음 (한도·세율은 과세연도 확인) |
| **신용카드 등** | 사용액 요건을 채우면 **소득공제** 가능 |
| **ISA** | **가입만으로 연말정산 세액공제가 생기지는 않음**. 계좌 안 수익 과세특례·만기 후 연금 이전 등 **별 트랙** |

ISA를 “연말정산 환급용 계좌”로 오해하면 기대가 어긋납니다.
계좌 절세는 [ISA 개요 글](https://mynews20482.tistory.com/49) 쪽에서, 급여 정산 공제는 이 시리즈에서 다룹니다.

## 6. 가정 예시로 보는 환급·추가납부

아래는 **가정 예시**입니다. 세율·공제 한도는 해당 과세연도 홈택스 기준으로 다시 넣으세요.

| 항목 | 가정 A (환급 쪽) | 가정 B (추가납부 쪽) |
| :--- | :--- | :--- |
| 총급여 | 4,800만 원 | 4,800만 원 |
| 기납부 원천징수 | 상대적으로 많음 | 상대적으로 적음 |
| 인적·월세·연금 공제 | 반영 큼 | 서류 누락·요건 미달 |
| 결과 감각 | 결정세액 < 기납부 → **환급** | 결정세액 > 기납부 → **추가납부** |

같은 급여라도 **공제 반영 여부**와 **원천징수 누적**에 따라 결과가 갈립니다.
그래서 “옆자리보다 환급이 적다”는 비교는 거의 의미가 없습니다.

## 7. 연간으로 보면 연말정산은 ‘시즌’이 아니다

실무적으로는 이렇게 나누는 편이 편합니다.

- **1~2월**: 간소화 확인, 서류 제출, 결과 확인
- **3~5월**: (필요 시) 경정청구·종합소득 보완
- **연중**: 부양 변동, 월세 계약, 연금 납입, 카드·현금영수증 습관
- **11~12월**: 연금·기부·의료비 등 **한도 안 막판 점검** (해당 연도 요건 확인)

막판에만 몰리면 한도를 넘기거나, 반대로 공제 기회를 놓칩니다.
시리즈 후반에서 홈택스 클릭 순서와 월별 캘린더로 다시 묶습니다.

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 환급 = 보너스라고 생각 | 미리 낸 세금의 **정산 결과**로 본다 |
| ISA 가입만으로 연말정산 공제 기대 | ISA는 **가입만으로 세액공제되지 않음** — 역할 분리 |
| 간소화에 없으면 포기 | 월세·일부 기부 등은 **직접 증빙** 제출 |

| 한도·세율을 작년 기억으로 고정 | **해당 과세연도** 국세청·홈택스 확인 |

## 실전 체크리스트

- [ ] 작년 원천징수영수증에서 **총급여·기납부·결정세액**을 찾아봤다
- [ ] 환급·추가납부가 **어떤 공제 항목**에서 갈렸는지 표시해 뒀다
- [ ] 부양가족·월세·연금·기부 중 **내년(또는 해당 연도)에 준비할 서류**를 목록화했다
- [ ] ISA·연금·카드의 절세 역할을 **서로 섞지 않고** 정리했다
- [ ] 회사 연말정산 일정(서류 마감일)을 캘린더에 넣었다
- [ ] 간소화에 안 뜨는 항목 후보를 따로 적어 뒀다
- [ ] 수치·한도는 **해당 과세연도 홈택스**에서 다시 본다고 메모했다

## 이번 화 전략

**초보 직장인**: 환급액보다 **원천징수영수증 한 장**을 이해하는 것이 1순위다. 총급여·기납부·결정세액·주요 공제란만 표시해 두면 이후 화가 쉬워진다.

**경력·이직자**: 중도입사·퇴사·겸업이 있으면 원천징수 누적이 들쭉날쭉하다. “환급이 적다”보다 **기납부  sufficiency**를 먼저 본다.

**부부·맞벌이**: 부양가족·월세·주택자금은 **한쪽에만** 넣는 경우가 많다. 누가 요건에 맞는지부터 나누고, 중복 신고는 피한다.

## 확인 권장

- **국세청·홈택스**: 연말정산 간소화, 공제 요건·한도, 원천징수영수증
- **근로복지공단·회사 인사/총무**: 제출 일정, 서류 양식
- **금융회사**: 연금·IRP·보험료 납입증명 (해당 시)

## 핵심 정리

1. 연말정산은 **기납부 vs 결정세액** 맞추기이며, 환급·추가납부는 그 차이다.
2. 소득공제와 세액공제의 체감이 다르니, 항목을 **표로 구분해** 본다.
3. ISA 가입만으로 연말정산 세액공제가 생기지 않는다 — **계좌 절세와 급여 정산을 분리**한다.
