- 여러 대출이 있으면 **실효 금리·연체 위험·수수료**로 순서를 정한다.

## 1. 왜 순서가 이자를 가르나

여유 자금이 한정되어 있으면, 어디에 먼저 넣느냐에 따라  
**다음 달 이자**와 **완제 속도**가 달라진다.  
모든 대출에 똑같이 나눠 넣는 것은 관리가 편해 보여도,  
이자 최소화와는 거리가 있을 수 있다.

전제 조건:

1. 모든 건의 **약정 최소 상환**은 지킨다 (연체 금지)  
2. 그 위에 생기는 **여유분**의 투입 순서를 정한다  
3. 중도상환수수료·해지 불이익을 계산에 넣는다  

## 2. 두 가지 대표 방법

| 방법 | 규칙 | 장점 | 한계 |
| :--- | :--- | :--- | :--- |
| **금리 우선** | 실효 금리 높은 순 | **총이자 절감**에 유리한 편 | 동기 부여가 약할 수 있음 |
| **잔액 우선** | 작은 잔액부터 완제 | **심리적 완주**·관리 단순화 | 고금리가 남으면 이자 손실 가능 |
| **위험 우선** | 연체 임박·변동 충격부터 | 신용·가계 붕괴 방지 | 이자 최적과 다를 수 있음 |

실무에서는 혼합이 흔하다.  
예: 연체 위험 건을 먼저 정상화 → 이후 고금리 순.

## 3. 실효 금리로 정렬하는 법

표에 적어 본다.

| 대출 | 잔액 | 금리 | 수수료·기타 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 현금서비스 | 80만 | **가정 15%** | — | 최우선 후보 |
| 카드론 | 400만 | **가정 12%** | — | |
| 신용A | 1,500만 | **가정 7%** | 중도 **가정 0.5%** | 수수료 감안 |
| 주담대 | 1.8억 | **가정 4%** | 중도 있음 | 면제 후 검토 |

금리는 **가정 예시**다. 본인 앱 수치로 교체한다.  
신용A에 수수료가 있으면, “지금 갚을 때의 순이득”을 7화 방식으로 재계산한다.

## 4. 심리적 방법(잔액 우선)을 쓸 때

작은 잔액부터 없애면 목록이 짧아져 관리 실수가 줄어든다.  
다만 고금리 큰 잔액이 오래 남으면 이자가 계속 나온다.

보완:

- 잔액 우선을 쓰더라도 **현금서비스·리볼빙**처럼 극단적 고금리는 예외로 먼저  
- 완제된 건의 월 상환액을 **다음 순위로 자동 이전**(눈덩이)  
- 분기마다 금리 순으로 **재정렬**할지 점검  

## 5. 여유 자금 투입 규칙(예시)

매월 급여 후:

1. 생활비·필수 고정비 확보  
2. 모든 대출 **최소(약정) 상환**  
3. 비상금 최소치 유지(과도한 제로화 지양)  
4. 남은 금액을 **1순위 대출**에만 추가 상환  
5. 1순위 완제 시 2순위로 월 여유 전체를 이동  

투자 수익률이 대출 금리보다 “높을 것 같다”는 이유로  
고금리 빚을 방치하는 선택은, 확정 이자 vs 불확정 수익의 비교다.  
가계 방어 관점에서는 **확정 고금리부터** 줄이는 편이 안전한 경우가 많다.

## 6. 주담대와 단기 고금리가 같이 있을 때

주담대 금리가 낮아 보여도, 현금서비스·카드론이 있으면  
여유 자금의 1순위는 대개 **단기 고금리**다.  
다만 주담대 연체가 임박했다면 **위험 우선**이 이자를 앞선다.

판단 보조:

- 연체 D-day가 가까운 건 → 위험 우선  
- 모두 정상 상환 중 → 실효 금리 우선  
- 주담대 중도수수료가 크면 → 면제·소액만, 고금리는 별도 집중  

“집 대출부터”라는 감정보다 **표의 숫자**를 따른다.

## 7. 가족·맞벌이 합의

순서가 사람마다 다르면 여유 자금이 분산된다.  
맞벌이·가족 공동이라면:

1. 공동 표에 대출을 모두 올린다(개인 정보 보호 범위 합의)  
2. 1순위를 **한 줄**로 합의한다  
3. 완제 시 다음 순위를 미리 적어 둔다  
4. 월 점검 15분을 고정한다  

합의 없는 “각자 알아서”는 연체 실수와 이자 낭비를 키운다.

## 핵심 숫자 (가정 예시)

| 항목 | 가정·기준 |
| :--- | :--- |
| 정렬 1키 | **실효 금리** (앱 적용금리) |
| 정렬 2키 | 연체까지 남은 **일수·금액** |
| 정렬 3키 | 중도수수료 **순이득** |
| 여유 투입 | 최소 상환 후 **1곳에 집중** |
| 재검토 | **분기 1회** 표 갱신 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 모든 대출에 균등 분할 | 최소 유지 + **1순위 집중** |
| 주담대만 열심히, 현금성 방치 | 고금리 단기부터 |
| 최소 상환을 깜빡 | 자동이체·캘린더 **이중 장치** |
| 수수료 무시하고 중도 | 손익분기 후 실행 |
| 순서 표가 없음 | 한 장 표로 **가족 공유** |

## 실전 체크리스트

- [ ] 전 대출을 잔액·금리·월납·수수료로 표에 적었다  
- [ ] 연체 위험이 있는 건을 표시했다  
- [ ] 1순위(여유 자금 투입처)를 정했다  
- [ ] 모든 건 최소 상환 자동이체를 확인했다  
- [ ] 1순위 완제 후 다음 순위 이전 규칙을 적어 두었다  
- [ ] 분기 재정렬 날짜를 캘린더에 넣었다  

## 이번 화 전략

**페르소나 A — 이자 최소화 집중**  
금리 우선. 현금·카드론을 먼저 없애고 신용→주담대 순.

**페르소나 B — 관리 피로·건수 많음**  
극단 고금리만 먼저 제거 후 잔액 우선. 건수를 줄여 연체 실수를 막는다.

**페르소나 C — 변동 주담대+신용**  
신용 고금리를 먼저 줄여 DSR·현금흐름을 확보한 뒤, 주담대는 면제·대환과 연계.

## 확인 권장

- **은행·카드 앱**: 적용금리, 최소상환, 중도상환  
- **신용정보원**: 누락된 채무·연체 여부  
- **금융감독원**: 다중채무·불법사금융 주의  
- **가계부·캘린더**: 상환일 충돌 점검  

## 핵심 정리

1. 최소 상환으로 **연체를 막고**, 여유는 **1순위에 집중**한다.  
2. 금리 순과 잔액 순은 목표가 다르니 **가계에 맞게** 고른다.  
3. 표는 **가정**이 아닌 본인 금리로 분기마다 갱신한다.
