# 왜 보험 점검이 필요한가 | 보험점검 (1화)

안녕하세요.
안대표입니다.

보험은 “가입하면 끝”이 아닙니다.
가족 구성, 소득, 집·차, 직장 단체보험이 바뀌어도 보험료는 매달 빠져나갑니다.
이번 시리즈는 **새 상품을 파는 글이 아니라**, 이미 가입한 계약을 **점검·정리·비교**하는 방법을 12화에 걸쳐 정리합니다.

## 30초 요약

- 보험 점검은 **가계 지출 절감**과 **필수 보장 유지**를 동시에 보는 일입니다.
- 초점은 특정 보험사·상품 추천이 아니라 **내 계약서·약관·보험료 고지서**입니다.
- 이 시리즈는 보장성·저축성 구분, 실손·진단비·자동차, 중복·갱신, 해지·감액 순서를 다룹니다.

보험을 “더 들어야 하나?”보다 먼저 물을 질문은 이것입니다.
**지금 내고 있는 보험료가, 지금 필요한 보장과 맞는가?**

---

## Q. 왜 ‘가입’보다 ‘점검’이 먼저일까?

많은 가계에서 보험은 월급에서 **고정비**처럼 나갑니다.
그런데 보장 내용은 가입 시점의 나이·가족·소득을 기준으로 짜여 있습니다.

이사가고, 아이가 생기고, 차가 바뀌고, 회사가 단체보험을 새로 들어도
개인 계약은 자동으로 맞춰지지 않습니다.
그래서 **점검 없이 추가 가입**하면 중복·과잉이 쌓이기 쉽습니다.

**점검은 해지가 목적이 아닙니다. 필요한 것은 남기고, 겹치거나 목적이 흐린 것을 정리하는 일입니다.**

## 1. 이 시리즈가 다루는 것

1. 보장성·저축성 **목적 구분**
2. 실손·진단비·사망·자동차 **계약 읽기**
3. 가족·단체보험까지 포함한 **중복 점검**
4. 갱신형 보험료 상승에 대비한 **부담 관리**
5. 보험료를 줄일 때의 **순서**(필수 유지 → 정리)
6. 해지·감액·특약 정리 **절차**
7. 비교견적·설계를 받을 때 **질문 리스트**
8. **연 1회** 점검 루틴

다루지 않는 것: 특정 보험사·상품 “이게 최고”, 수익률 보장, 가입 권유.

## 2. 점검이 필요한 네 가지 신호

| 신호 | 예시 | 점검 방향 |
| :--- | :--- | :--- |
| **지출 압박** | 보험료가 월급의 큰 비중 | 필수·비필수 구분 |
| **가족 변화** | 결혼·출산·독립·이혼 | 수익자·보장금액 |
| **보장 공백 불안** | “뭔가 부족한 것 같아” 추가 가입 | 계약 목록부터 |
| **갱신 고지** | 보험료가 눈에 띄게 오름 | 갱신형·실손 세대 |

불안만으로 설계서를 새로 받으면, 기존 계약과 **겹치는 특약**이 또 붙기 쉽습니다.
먼저 **보유 계약 목록**을 한 장으로 만드세요.

## 3. 점검의 범위 (시리즈 공통)

| 구분 | 포함 | 비고 |
| :--- | :--- | :--- |
| **보장성** | 실손, 진단비, 수술·입원, 사망, 운전자·자동차 | 가계 위험 대비 |
| **저축·투자성** | 연금저축성, 변액, 일부 종신 환급형 등 | 목적·수익률·수수료 별도 |
| **직장·단체** | 회사 단체상해·실손 특약 | 개인과 중복 여부 |
| **가족 합산** | 배우자·자녀 명의 계약 | 가구 단위로 보기 |

자동차보험은 “매년 갱신”이라 별도 리듬이 있습니다.
실손·장기보장성은 “오래 묵은 계약”일수록 약관·세대·갱신 주기를 다시 읽어야 합니다.

## 4. 한 장 목록부터 — 템플릿

아래 열만 채워도 이후 점검이 쉬워집니다.

| 열 | 적을 내용 |
| :--- | :--- |
| **보험사·상품명** | 증권·앱에 나온 이름 |
| **계약일·만기** | 가입·보장 종료 |
| **월 보험료** | 특약 포함 합계 |
| **주계약·특약** | 실손 / 암 / 뇌·심장 / 사망 등 |
| **갱신 여부** | 갱신형·비갱신형·주기 |
| **수익자** | 사망·진단 시 누구 |
| **메모** | 단체보험과 겹침 의심 등 |

금액은 **가정 예시**가 아니라 **내 고지서 숫자**를 넣습니다.
표가 없으면 실수·중복을 눈으로 못 봅니다.

## 5. 시리즈가 지키는 원칙

1. **계약서·약관이 최우선** — 블로그 요약보다 내 문구가 맞습니다.
2. **특정 상품 권유 없음** — “어떤 회사 몇 호”를 팔지 않습니다.
3. **필수 보장 유지** — 보험료만 줄이려다 꼭 필요한 담보를 지우지 않습니다.
4. **확인 창구** — 금융감독원, 보험다모아, 보험사 고객센터·앱을 안내합니다.

수치가 나오는 회차도 **2026-07 기준의 일반적 구조**를 설명합니다.
세대·자기부담·특약 이름은 가입 시점·상품마다 다르니, 최종 판단은 약관입니다.

## 핵심 숫자·기준 (시리즈 앵커)

| 항목 | 기준 | 비고 |
| :--- | :--- | :--- |
| **점검 단위** | **가구·계약 목록** | 명의가 달라도 합산 |
| **우선 자료** | **증권·약관·보험료 고지** | 설계서만으로 판단 금지 |
| **실손** | **비례보상** 구조가 일반적 | 중복 가입 ≠ 중복 수령 |
| **절감 원칙** | **필수 유지 → 중복·비필수 정리** | 해지 순서가 중요 |
| **수치 기준일** | **2026-07** | 상품·특약은 개인 약관 우선 |

**자영업·프리랜서**
- 소득 변동이 크면 갱신형 부담이 더 크게 느껴집니다.

**중년·은퇴 준비**
- “예전 보험이 최고”라는 말보다 **지금 보험료·보장 종료 나이**를 봅니다.
- 환급·해지환급금에만 끌려 보장을 비우지 않도록 원칙만 적어 둡니다.

## 확인 권장

- **금융감독원** — 보험 계약 조회·민원·약관 이해 자료

## 핵심 정리

1. 보험 점검은 판매가 아니라 **기존 계약을 목적에 맞게 재정렬**하는 일입니다.
2. 시작은 **가구 단위 계약 목록**과 월 보험료 합계입니다.
3. 이 시리즈는 필수 보장을 지키면서 **중복·목적 혼동·갱신 부담**을 줄이는 순서를 다룹니다.

# 보장성 vs 저축성 구분 | 보험점검 (2화)

안녕하세요.
안대표입니다.

1화에서 계약 목록을 만들었다면, 이번엔 각 계약을 **목적**으로 나눕니다.
보험료가 비싼데 보장이 약하거나, 반대로 저축인 줄 알았는데 수수료·사업비가 큰 경우가 흔합니다.
**보장성**과 **저축성(또는 투자·연금성)**을 섞어 보면 점검이 꼬입니다.

## 30초 요약

- 보장성은 **위험(질병·사망·배상 등)에 대비**하는 계약, 저축성은 **납입·적립·환급·연금액**이 목적인 계약에 가깝습니다.
- 같은 “종신·연금”이라도 특약·환급 구조에 따라 성격이 달라지니 **주계약 목적**을 먼저 읽습니다.
- 점검은 “어떤 게 이득인가”보다 **지금 목적과 맞는지**입니다.

## Q. 왜 구분이 먼저일까?

보장 공백을 저축성 상품으로 메우려 하거나,
목돈 마련을 보장성 특약 더미로 해결하려 하면 **비용 대비 목적**이 어긋납니다.

**목적 태그**를 붙여 두면, 보험료를 줄일 때 “무엇을 손댈지”가 명확해집니다.

## 1. 한눈에 보는 구분

| 구분 | 주된 질문 | 대표 예(유형) |
| :--- | :--- | :--- |
| **보장성** | 사고·질병·사망 시 **얼마가 나오나** | 실손, 진단비, 정기·종신(보장 중심), 자동차·운전자 |
| **저축·연금성** | 납입 후 **얼마가 쌓이거나 나오나** | 연금보험, 일부 저축성·변액, 교육·목돈형 |
| **혼합** | 보장 + 환급·적립이 한 증권 | 환급형 종신·저축특약 부착 상품 등 |

혼합형은 표에서 **주계약이 보장인지 적립인지**를 메모하세요.
광고 문구의 “돌려받는다”만 보고 저축으로 분류하면 오류가 납니다.

## 2. 증권에서 목적 읽는 법

1. **주계약 명칭** — 실손, 암, 정기, 종신, 연금 등  
2. **특약 목록** — 진단·수술·입원·운전자 등이 보장성 신호  
3. **해지환급금·적립액 안내** — 저축·환급 성격 신호  
4. **사업비·수수료 안내**(해당 시) — 투자·변액성에서 특히 중요  
5. **보험료 구성** — 보장보험료 vs 적립보험료 구분 표기 여부

앱·증권에 “보장보험료 / 적립보험료”가 나뉘어 있으면 분류가 쉽습니다.
없으면 특약·환급 구조를 보고 **대략 태그**만 달아도 충분합니다.

## 3. 목적 혼동이 만드는 세 가지 낭비

| 혼동 | 결과 | 점검 메모 |
| :--- | :--- | :--- |
| 저축 목적으로 보장성 과다 | 월 고정비만 커짐 | 목적 = 저축? 보장? |
| 보장 목적으로 환급형만 고집 | 같은 보장에 **보험료↑** | 순수보장 vs 환급 비교 |
| 실손·진단비를 ‘투자’로 인식 | 해지·유지 판단 왜곡 | 의료비·진단은 **위험 대비** |

**환급이 있다고 해서 좋은 저축은 아닙니다.**
사업비·중도 해지 시 원금 미달·공시이율 변동을 계약서에서 확인해야 합니다.

## 4. 가구 표에 ‘목적’ 열 추가

1화 목록에 열을 하나 더합니다.

| 계약 | 월 보험료 | 목적 태그 | 남길 이유(한 줄) |
| :--- | :--- | :--- | :--- |
| (예) 실손 | 3만 | **보장-의료** | 의료비 실 대비 |
| (예) 암 진단 | 2만 | **보장-진단** | 치료·생활비 버퍼 |
| (예) 연금성 | 20만 | **저축-연금** | 노후 적립 목적 |
| (예) 종신+특약 | 15만 | **혼합** | 사망+특약 — 분리 검토 |

숫자는 **가정**이 아니라 본인 고지서로 바꾸세요.
태그만 달려도 이후 중복·감액 논의가 빨라집니다.

## Q. 실손 ‘세대’는 왜 보나?

실손 표준화·개정 시점에 따라 자기부담률, 보장 범위, 비급여 특약 구조가 달랐습니다.
인터넷의 “몇 세대가 무조건 좋다”는 말보다 **내 계약의 약관**이 맞습니다.
세대 라벨은 **읽는 지도**일 뿐입니다.

## 1. 가입 시기와 세대(대략적 구분)

아래는 **일반적인 설명용 구분**입니다. 개별 상품·특약은 약관이 우선합니다.

| 구분(통칭) | 대략적 가입 시기 | 점검 때 자주 보는 점 |
| :--- | :--- | :--- |
| **1세대** | 표준화 이전(~2009.9 전후) | 자기부담·갱신·보장 범위가 계약마다 다름 |
| **2세대** | 표준화 이후~2017.3 전후 | 표준화 약관, 자기부담 구조 확인 |
| **3세대** | 2017.4~2021.6 전후 | 특약·자기부담 변화, 갱신 주기 |
| **4세대** | 2021.7 이후 전후 | 급여·비급여 분리, 비급여 특약·할인할증 등 |

증권에 “몇 세대”라고 찍혀 있지 않을 수 있습니다.
**보장개시일·상품명·약관 버전**으로 보험사에 확인하는 것이 정확합니다.

## 2. 자기부담 — 숫자로 메모

실손 청구 시 “전부 보험에서”가 아닙니다.
자기부담금·자기부담률·연간 자기부담 상한 등이 약관에 있습니다.

| 메모 항목 | 적을 내용 |
| :--- | :--- |
| **급여 자기부담** | 비율·최소 금액(약관) |
| **비급여** | 특약 가입 여부·자기부담 |
| **통원·처방** | 회당·일 한도 등 |
| **연간 한도** | 보상 한도·자기부담 상한 |

병원비가 나와도 **자기부담 + 비보장**이 남습니다.
진단비(4화)와 역할이 다르니 섞지 마세요.

## 3. 중복 실손 — 왜 보험료만 나갈까

실손은 여러 계약을 들어도, 통상 **실제 부담한 의료비 범위**에서 보험사들이 나눠 지급하는 구조입니다.
“두 개면 두 배”가 아닙니다.

| 상황 | 의미 | 점검 |
| :--- | :--- | :--- |
| 개인 실손 2개 | 보험료 이중, 보상은 비례 | 유지 필요성 검토 |
| 개인 + 단체 실손 | 직장 퇴직 시 공백 가능 | 단체 범위·퇴직 후 |
| 가족 카드·자녀 | 명의·종피보험자 확인 | 중복 특약 |

정리·해지는 보험사 절차를 따르고, 이번 화에서는 **중복 여부 표시**만 합니다.

## 4. 갱신·보험료 고지

실손은 갱신형인 경우가 많아 **연령·손해율·세대 구조**에 따라 보험료가 오를 수 있습니다.
고지서를 연 1회 모아 두면 갱신형 보험료 추이 점검과 연결됩니다.

| 볼 것 | 이유 |
| :--- | :--- |
| **갱신 주기** | 1년·갱신형 여부 |
| **최근 2~3회 보험료** | 상승 속도 |
| **할인·할증**(해당 시) | 4세대 등 비급여 관련 안내 |

“예전 실손이니까 무조건 유지”도, “무조건 새 세대로”도 단정하지 않습니다.
**자기부담·보장 범위·보험료 경로**를 표로 비교한 뒤 결정합니다.

## 5. 실손과 다른 의료 특약

| 담보 | 역할 | 실손과의 관계 |

| **진단비** | 진단 시 목돈 | 치료비·생활비 버퍼 |

“실손 있으니 진단비 불필요”는 가구·현금 버퍼에 따라 달라집니다. **추천이 아니라 역할 구분**입니다.

이번 화는 **이미 가입한 진단비 특약**을 읽는 법입니다.

## 30초 요약

## Q. 실손이 있는데 진단비는 왜 보나?

실손은 의료비 영수증에 가깝고, 진단비는 **생활비·간병·비급여 공백**을 메우는 목돈에 가깝습니다.
역할이 다릅니다. “실손 있으니 진단비 불필요”는 가구 현금 버퍼에 따라 달라지며, 여기서는 **역할을 섞지 말 것**만 강조합니다.

## 1. 진단비가 묻는 세 질문

| 질문 | 증권·약관에서 |
| :--- | :--- |
| **무엇이** | 암 / 뇌혈관 / 심장 등 **정의된 질병** |
| **언제** | 진단 확정·입원·수술 등 **지급 사유** |
| **얼마** | 가입금액·감액·회당 한도 |

이름에 “뇌”가 있어도 **뇌졸중만**인지, **뇌혈관질환 전반**인지가 다릅니다.
심장도 **급성심근경색**과 **허혈성심장질환** 범위가 상품마다 달랐습니다.

## 2. 암 특약에서 자주 보는 포인트

| 항목 | 점검 |
| :--- | :--- |
| **일반암 vs 유사암·소액암** | 갑상선·기타피부 등 가입금액 축소 여부 |
| **면책·감액기간** | 가입 후 일정 기간 미지급·삭감 |
| **재진단·고도후유** | 특약 유무·정의 |
| **원발·전이** | 약관 조항 |
| **상피내암 등** | 별도 분류·금액 |

“암이면 무조건 가입금액 전액”이 아닙니다.
**진단서·조직검사 등 약관이 요구하는 증빙**도 미리 알아두면 청구 때 덜 당황합니다.

## 3. 뇌·심장 — 정의 표로 고정

보유 특약을 아래처럼 옮겨 적습니다.

| 특약명(증권) | 약관상 보장 질환(요약) | 가입금액 | 비고 |
| :--- | :--- | :--- | :--- |
| (예) 뇌졸중진단 | 약관 코드·정의 메모 | ○○만 | 뇌경색 포함 여부 |
| (예) 급성심근경색 | 정의·제외 | ○○만 | 협심증 제외 여부 |

인터넷 후기보다 **약관 조항 번호**를 메모하는 편이 안전합니다.
보험사 앱의 “보장 상세”만으로 부족하면 약관 PDF를 받습니다.

## 4. 중복 진단비와 가족 합산

정액 진단비는 실손과 달리 **중복 가입 시 각각 지급**되는 경우가 많습니다.
그렇다고 “많을수록 좋다”가 점검의 결론은 아닙니다.

| 상황 | 볼 점 |
| :--- | :--- |
| 동일 질환 특약 여러 개 | 월 보험료 합 vs 필요 목돈 |
| 부부 각자 | 가구 필요액·수익자 |
| 갱신형 진단 특약 | 보험료 상승(8화) |

필요 목돈은 **치료·휴직·고정비 N개월**처럼 가구가 정한 가정이 있어야 합니다.
가정 금액은 예시일 뿐, 여기서 상품을 권하지 않습니다.

## 5. 진단비와 수술·입원 일당

| 담보 | 지급 트리거 | 메모 |
| :--- | :--- | :--- |
| **진단비** | 약관상 진단 확정 등 | 목돈 |
| **수술비** | 약관 수술 분류 | 횟수·종류 |
| **입원일당** | 입원일수 | 단기 입원 트렌드와 괴리 가능 |

최근 의료 패턴상 단기 입원·통원이 늘면 입원일당만으로 부족할 수 있습니다.
**보유 담보의 트리거**만 정확히 알면, 불안 쇼핑을 줄일 수 있습니다.

## Q. ‘종신이 무조건 좋다’는 말에 어떻게 답할까?

종신은 보장 기간이 길다는 장점이 있지만, 같은 가입금액이면 보험료 부담이 커지는 경우가 많습니다.
반대로 정기는 기간이 끝나면 보장이 사라집니다.
**좋은 상품**이 아니라 **지금 가구의 필요 기간**에 맞는지가 점검 기준입니다.

## 1. 유형만 먼저 태그

| 유형 | 핵심 | 점검 메모 |
| :--- | :--- | :--- |
| **정기** | 만기·갱신 기간 내 사망 시 | 만기 후 공백 |
| **종신** | 평생(약관·유지 조건) | 보험료·환급·특약 |
| **혼합·환급형** | 사망 + 적립·환급 | 2화 목적 분리 |
| **특약 사망** | 질병·상해 사망 특약 | 주계약과 중복 |

증권에 “종신”이어도 특약만 정기인 경우가 있습니다.
**주계약·특약별 만기**를 따로 적으세요.

## 2. 필요 금액 — 가정식으로만

여기서 제시하는 숫자는 **가정 예시**입니다. 개인 권고액이 아닙니다.

| 구성(가정) | 예시 질문 |
| :--- | :--- |
| **부채** | 주택담보·신용대출 잔액 |
| **생활비** | 배우자·자녀 연 생활비 × N년 |
| **일시** | 장례·정리 비용 |
| **차감** | 배우자 소득·예금·단체사망·이미 든 사망보험 |

> 필요액(가정) ≈ 부채 + 생활비 버퍼 − 대체 재원 − 기존 사망보장 합

표로 적어 두면 “막연히 더”가 줄어듭니다.
대체 재원에 예금을 넣는다고 해서 예금 해약을 권하는 것이 아닙니다.

## 3. 필요 기간

| 가구 상황 | 기간을 보는 관점 |
| :--- | :--- |
| **미성년 자녀** | 자녀 독립·학비 구간 |
| **주택담보** | 대출 잔존 기간 |
| **맞벌이** | 한쪽 소득 상실 시 회복 기간 |
| **부채 적음·자산 충분** | 사망보장 규모 축소 검토 여지 |

기간이 짧아졌는데 종신 고액만 남아 있으면 **감액·특약 정리** 후보가 됩니다.
반대로 기간이 남았는데 정기 만기가 임박하면 **공백** 후보입니다. (신규 가입 권유 아님)

## 4. 수익자·단체보험

| 항목 | 확인 |
| :--- | :--- |
| **수익자** | 배우자·자녀·상속 이슈 |
| **수익자 변경** | 이혼·재혼 후 미변경 |
| **직장 단체** | 사망·유족 특약 금액 |
| **대출 단체·신용생명** | 담보대출 연계 여부 |

개인 사망보험만 보고 단체·신용생명을 빼먹으면 **중복·과잉**으로 보일 수 있고,
단체만 믿으면 퇴직 시 **공백**이 생깁니다.

## 5. 환급·해지환급금에 끌릴 때

## Q. 이름이 다르면 중복이 아닌가?

“암수술비”와 “질병수술비”는 이름이 달라도 같은 수술을 두 번 보장할 수 있습니다.
반대로 이름은 비슷해도 약관 정의가 다르면 공백일 수 있습니다.
**약관 지급 사유**로 묶는 것이 안전합니다.

## 1. 중복 맵 템플릿

가구 단위로 아래 표를 만듭니다.

| 위험(열) | 계약A | 계약B | 단체 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **실손(의료비)** | O/X | O/X | O/X | 비례·중복 수령↓ |
| **암 진단** | 금액 | 금액 | 금액 | 정액 합산 가능 |
| **뇌·심장 진단** | | | | 정의 확인(4화) |
| **사망** | | | | 5화·신용생명 |
| **운전자·교통** | | | | 자동차·운전자 장기 |
| **배상책임** | | | | 일상생활·자동차 |

O/X와 금액만 채워도 “겹침 후보”가 드러납니다.
해지는 아직 하지 않습니다. **표시만** 합니다.

## 2. 실손형 vs 정액형

| 유형 | 중복 시 흔히 | 점검 행동 |
| :--- | :--- | :--- |
| **실손** | 보험료만 이중, 보상은 실손 한도 내 | 유지 필요성·단체 공백 |
| **정액** | 조건 충족 시 **각각** 지급 가능 | 필요 목돈 vs 합계 |
| **일당·수술** | 중복 지급 가능 | 실제 입원·수술 패턴 |

“중복=무조건 해지”가 아닙니다.
실손은 이중 납입 낭비가 크기 쉽고, 정액은 **필요액 초과**일 때 후보가 됩니다.

## 3. 가족·단체에서 놓치기 쉬운 곳

| 출처 | 확인할 것 |
| :--- | :--- |
| **배우자 명의** | 실손·진단·운전자 |
| **자녀** | 부모 실손 종피보험자 + 자녀 전용 |
| **직장 단체** | 실손·상해·사망·진단 특약 한도 |
| **신용카드·은행** | 무료 상해·여행 특약(범위 협소) |
| **자동차** | 자상·무보험차 vs 운전자보험 |

단체보험은 퇴직·휴직·계약 변경 시 사라질 수 있습니다.
개인 계약을 줄일 때 **단체 의존도**를 메모하세요.

## 4. ‘유사 중복’ 체크 질문

1. 같은 진단코드·수술에 **두 특약이 동시에** 해당하는가?  
2. 실손이 두 개인가, 정액이 두 개인가?  
3. 자동차와 운전자 장기에서 **변호사비·벌금·부상**이 겹치는가?  
4. 사망이 종신+정기+단체+신용생명으로 **합산 과잉**인가?  
5. 일상생활배상과 자동차 대물이 **사고 유형**에서 역할이 다른가?

5번은 이름이 비슷해도 적용 현장이 다릅니다.

# 갱신형 vs 비갱신형 | 보험점검 (8화)

안녕하세요.
안대표입니다.

보험료가 “지금은 괜찮은데” 하다가, 갱신 고지에서 크게 오르는 경우가 있습니다.
실손·일부 진단·운전자 특약이 갱신형인 경우가 많고, 비갱신형은 초기에 더 비싸 보여도 **연령 상승분**이 다르게 움직입니다.
이번 화는 상품 추천이 아니라 **보유 계약의 갱신 구조와 보험료 경로**를 읽는 법입니다.

## 30초 요약

- **갱신형**은 주기마다 보험료가 재산정될 수 있고, **비갱신형**은 만기까지 보험료가 고정되는 구조가 일반적입니다(특약·상품별 예외 가능).
- 점검은 “어느 쪽이 이득”보다 **내 계약이 어떤지·최근 고지 추이**입니다.
- 상승이 가파르면 절감 순서·감액·특약 정리 후보로 연결합니다.

## Q. 갱신형이 ‘나쁜’ 보험인가?

아닙니다.
초기에 보험료가 낮아 진입이 쉬운 면도 있고, 실손처럼 구조상 갱신이 흔한 영역도 있습니다.

| **비갱신형** | 만기까지 동일 설계가 흔함 | 초기 수준·납입 기간 |
| **혼합** | 특약별 상이 | 특약마다 표시 |

## 3. 왜 오를 수 있나(개념)

| **7** | 필수 담보 **해지** | 최후 — 대체·공백 확인 |

순서는 일반론입니다. 가구마다 1~2순위가 바뀔 수 있으나,
**필수 해지를 1순위로 두지 않는 것**이 공통입니다.

## 2. ‘필수’ 표시 기준(체크용)

단정이 아니라 **표시용 질문**입니다.

| 질문 | 예 |
| :--- | :--- |
| 의료비 바닥이 있는가 | 실손(개인·단체) |
| 법적·운행 의무가 있는가 | 자동차 의무 담보 |
| 부채·부양 공백이 큰가 | 사망 필요액·기간(5화) |
| 정액 목돈 버퍼가 필요한가 | 진단비 — 가구 가정 |

필수가 아니면 바로 해지가 아니라 **후보**입니다.
단체로 대체 가능한지도 7화 맵을 봅니다.

## 5. 저축성과 보장성 절감을 섞지 말기

저축·연금성 납입을 줄이는 것은 **가계 저축 전략** 문제일 수 있습니다.

| 버킷 | 결정 기준 |
| :--- | :--- |
| **보장성** | 위험·중복·필수 |
| **저축성** | 목표 금액·대안 계좌·수수료 |

## 1. 상대에게 먼저 말할 문장(예시)

> 새 상품 가입이 목적이 아니라, **기존 계약 점검** 중입니다.  
> 필수 후보는 A, 중복 후보는 B입니다.  
> 동일 조건 비교와 **약관 차이**만 설명해 주세요.

이 문장이면 불필요한 특약 나열이 줄어듭니다.
