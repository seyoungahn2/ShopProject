# 일반형 → 서민형 전환, 서류와 타이밍 | ISA계좌 (34화)

안녕하세요.
안대표입니다.

ISA를 일반형으로 시작했다가,
소득 조건을 보니 **서민형**이 될 수 있겠다 싶은 분들이 많습니다.

비과세 한도가 **200만 원에서 400만 원**으로 늘어납니다.
같은 수익이면 세금 부담이 확 달라지죠.

그런데 “서민형으로 바꿔 주세요” 한마디로 끝나지 않습니다. **언제, 어떤 서류로, 어느 연도 소득 기준**인지 헷갈리면 한 해를 날릴 수 있습니다.

오늘은 **일반형 → 서민형(또는 농어민형) 전환**을 실무 순서로 정리하겠습니다.

## 30초 요약

- 서민형은 비과세 **200만 → 400만 원** — 납입 한도는 **동일** (현행).
- 자격은 **직전 연도 소득** 기준 — 홈택스 **소득확인증명서**가 출발점.
- **2~3월 제출 기한**을 놓치면 그해 400만 적용이 늦어질 수 있습니다.

---

## Q. “서민형”이면 소득이 아주 낮아야 하나?

아닙니다. **총급여 5,000만 원 이하** 직장인도 자주 해당됩니다.
본인 조건을 **숫자로** 확인하는 게 먼저입니다.

## 1. 서민형이 뭐가 다른가

| 구분 | 일반형 | 서민형·농어민형 |
| :--- | :--- | :--- |
| **비과세 한도** | **200만 원** | **400만 원** |
| **초과분** | **9.9%** 분리과세 | **9.9%** 분리과세 |
| **납입 한도** | 연 2,000만·총 1억 | **동일** |
| **자격** | 별도 소득 상한 없음 | **소득 요건 충족** 필요 |

“서민형”이라는 이름 때문에 소득이 아주 낮은 사람만 해당된다고 오해하기 쉬운데,
실무에서는 **총급여 5,000만 원 이하** 같은 직장인도 자주 해당됩니다.
본인 조건을 숫자로 확인하는 게 먼저입니다.

---

## 2. 자격 요건, 어떤 연도 소득을 보나

서민형 자격은 보통 **직전 연도** 소득으로 판단합니다.

대표적으로 알려진 기준(시점·유형에 따라 세부 확인 필요):

- **근로소득자**: 직전 연도 **총급여 5,000만 원 이하**
- **종합소득**: 직전 연도 **종합소득금액 3,800만 원 이하** 등

농어민형은 별도 요건이 있으니, 해당되면 금융사 안내를 봅니다.

**올해 급여가 4,800만 원이면, 내년에 서민형 신청** 같은 식으로 **1년 시차**가 생깁니다.
연말에 급여가 올라 5,200만 원이 되면, **그 해 직전 연도 기준**으로 다시 따집니다.

---

## 3. 전환 서류: 홈택스가 출발점

### 핵심 서류

**소득확인증명서( ISA 가입용 )** — 홈택스에서 발급

절차 요약:

1. 국세청 **홈택스** 로그인
2. 증명서 발급 메뉴에서 **ISA 가입용 소득확인증명서** 신청
3. 발급 후 **ISA 계좌 개설·유지 금융사**에 제출
4. 금융사 심사 후 **서민형(또는 농어민형) 적용**

증권사·은행마다 제출 방법(앱 업로드, 방문, 팩스)이 다릅니다. **올해 ISA를 연장·유지하는 곳**에 맞춰 제출하세요.

### 같이 챙길 것

- 신분증
- ISA 계좌 정보
- 금융사가 요구하는 **전환 신청서** (온라인 양식)

---

## 4. 타이밍: 언제 신청해야 하나

### 원칙

서민형 적용은 **해당 과세연도 ISA 비과세 한도**에 영향을 줍니다.
늦게 신청하면 **그해 일부 기간 일반형 한도**로 지나갈 수 있습니다.

실무 팁:

| 시점 | 할 일 |
| :--- | :--- |
| **1~2월** | 직전 연도 소득 확정·홈택스 자료 정리 |
| **2~3월** | 소득확인증명서 발급·금융사 제출(**서민형 적용 마감** 안내 확인) |
| 연중 | 급여·소득 변동 시 **내년 자격** 재점검 |
| **11~12월** | 내년 서민형 유지 가능한지 미리 보기 |

금융사마다 **“매년 3월까지”** 같은 내부 마감 안내가 있습니다.
**“언제까지 제출해야 올해 400만 적용되나”**를 고객센터에 한 번 확인하는 게 좋습니다.

### 신규 가입 vs 기존 계좌 전환

- **새로 ISA를 연다**: 개설 시 서민형 선택 + 서류 제출
- **이미 일반형 운용 중**: **유형 전환 신청** + 서류 제출

이미 일반형으로 한 해를 돌렸다면, **전환 승인 시점 이후** 비과세 한도가 어떻게 잡히는지 금융사 설명을 받으세요.

---

## 5. 전환해도 안 되는 경우

| 상황 | 이유 |
| --- | --- |
| 직전 연도 소득이 기준 초과 | 서민형 요건 미충족 |
| 서류 미제출·기한 경과 | 일반형 유지 |
| 종합과세 등 가입 제한 | 애초에 ISA 가입·유지 자체 문제 |
| 농어민형 요건 불일치 | 유형 선택 오류 |

“작년엔 됐는데 올해는 안 된다”도 흔합니다.
급여 인상·부수입 증가 시 **일반형으로 돌아가는 것**도 정상 시나리오입니다.

## 6. 부부·가구에서의 전환(32화 연계)

부부 중 **한쪽만** 서민형이면,

- 서민형 계좌: 비과세 400만 · 과세 수익 큰 운용 검토
- 일반형 계좌: 납입·성장 비중

으로 나누는 전략이 앞서 이야기한 패턴과 맞습니다.

**둘 다 서민형**이면 가구 비과세가 **800만 원**까지 넓어집니다(각 400만).
다만 **각자 서류·각자 제출**입니다. 배우자 명의로 대신 신청하는 구조가 아닙니다.

## 7. 오해하기 쉬운 것

### ① “서민형이면 세금이 아예 없다”

아닙니다. **순이익 400만 원까지** 비과세이고, 초과분은 **9.9%**입니다.

### ② “전환하면 납입 한도도 늘어난다”

납입 한도는 일반형·서민형 **동일(연 2,000만·총 1억, 현행)**입니다.
늘어나는 건 **비과세 한도**입니다.

### ③ “비과세 500만·1,000만으로 오른다”

상향 **논의**는 있으나 **미확정**입니다.
전환 계획은 **현행 200만·400만** 기준으로 하세요.

### ④ “서민형이면 어떤 상품이든 더 유리”

계좌 유형과 상품 수익 구조는 별개입니다.
국내주식 매매차익만 크면 ISA 이점이 작을 수 있다는 2화 이야기도 그대로입니다.

## 8. 급여 인상·이직 시나리오

### 시나리오 A: 올해 총급여 4,900만 → 내년 5,400만

- **올해(내년 ISA 유형 적용 기준)**: 직전 연도 4,900만 → **내년 서민형 신청 가능**할 수 있음
- **그다음 해**: 직전 연도 5,400만 → 서민형 **탈락**, 일반형 유지

급여가 경계선(5,000만) 근처면, **보너스·성과급 시점**에 올해 총급여가 튈 수 있습니다.
연말에 **내년 서민형 가능 여부**를 미리 계산해 두면 34화 전환 타이밍이 덜 헷갈립니다.

### 시나리오 B: 프리랜서·사업소득

종합소득금액 기준이 적용될 수 있어, 근로소득자와 **서류·확인 경로**가 다를 수 있습니다.
홈택스 발급 화면에서 **본인에게 해당하는 증명서**를 선택하세요.

- [ ] 홈택스 소득확인증명서(ISA 가입용) 발급

농어업 종사 등 **별도 요건**이 있습니다. 해당되면 일반형→서민형과 **유사한 서류 경로**이나, 금융사 안내를 따로 확인하세요.
