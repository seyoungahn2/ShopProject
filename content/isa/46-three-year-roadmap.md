## Q. 왜 3년이 기준축일까?

세제혜택을 온전히 쓰려면 **의무 3년**이 최소 단위이고, 납입·비과세·만기 출구도 **3년 호흡**에 맞춰 읽기 좋기 때문입니다.

## 1. 3년이 왜 기준축인가

세제혜택을 제대로 받으려면 **의무 가입기간 3년**을 채워야 합니다.
3년 전에 해지하면 혜택 소멸·추징 리스크가 있습니다.

동시에 ISA의 숫자들도 3년 단위로 읽기 좋습니다.

| 항목 | 내용 |
| :--- | :--- |
| **비과세** | 일반형 **200만 원** / 서민형 **400만 원** (순이익 기준) |
| **초과분** | **9.9%** 분리과세 |
| **납입** | 연 **2,000만 원**, 총 **1억 원**, 미사용분 **이월** |
| **중도인출** | **납입 원금** 범위 내 가능 |
| **만기 출구** | 연금 전환 시 **10%**, 최대 **300만 원** 추가 세액공제, **약 60일** 이내 |

3년은 “참으라”는 기간이 아니라 **제도를 온전히 쓰는 최소 단위**에 가깝습니다.

## 2. Year 0 — 개설 전~가입일 (준비)

### 해야 할 일

1. **가입 자격** — 만 19세 이상, 1인 1계좌
2. **종합과세 이력** — 직전 3개 과세기간 중 해당 이력 있으면 가입 제한 가능
3. **일반형 vs 서민형** — 비과세 200만 vs **400만**
4. **유형 선택** — 중개형 / 신탁형 / 일임형
5. **납입·운용 계획** — 연 2,000만 원 중 올해 목표, 상품 범위(해외 **직접** 불가)

### 마인드셋

“돈 모이면 만들게”보다 **일찍 개설**이 낫다는 제 생각은 여기서 시작합니다.
의무기간 시계는 **가입일부터** 갑니다.

## 3. Year 1 — 첫해: 계좌에 몸 익히기

| 분기 | 초점 | 체크 |
| :--- | :--- | :--- |
| **Q1** | **개설·첫 납입·상품군** 방향 | 41화 체크리스트 |
| **Q2** | **월 납입** 습관·비중 | 42화 납입표, 43화 상품군 |
| **Q3** | **손익통산** 감각 | 계좌 **순이익**, 종목별 X |
| **Q4** | **연말 한도**·내년 계획 | 올해 **2,000만 원** 사용률 |

첫해 목표는 **수익률 1위**가 아니라 **끊기지 않는 납입 + 월 점검**(44화)입니다.

비과세 한도를 채우지 못해도 괜찮습니다.
다만 **과세 수익**이 늘어날수록 한도 의식은 커집니다.

## 4. Year 2 — 둘째 해: 최적화·가족 전략

| 분기 | 초점 | 체크 |
| :--- | :--- | :--- |
| **Q1** | 작년 대비 **납입·비중** 조정 | 이직·소득 변화 반영 |
| **Q2** | **리밸런싱·비용** 점검 | 20화·9화 |
| **Q3** | **부부 ISA·서민형** 재확인 | 32화·34화 |
| **Q4** | 2년 차 연말, **만기 1년 전** 준비 시작 | 누적 납입·순이익 추이 |

둘째 해부터는 **9.9% 구간**에 들어가는지, **비과세 200·400** 진행도를 참고로 봅니다.
“올해 꼭 채워야 한다”는 압박보다 **추이**가 중요합니다.

가족이 있다면 **누구 계좌에 어떤 역할**을 둘지 32화 관점으로 정리하기 좋은 시기입니다.

## 5. Year 3 — 셋째 해: 만기·출구 설계

| 분기 | 초점 | 체크 |
| :--- | :--- | :--- |
| **Q1** | **만기 예정일** 확인 | 금융사 앱·계약서 |
| **Q2** | **해지 vs 연금 전환** 시나리오 | 30화·31화 |
| **Q3** | 만기 6개월 전 — **자금 용도** 결정 | 생활비 / 재투자 / 연금 |
| **Q4** | **만기** — **60일** 이내 연금 전환 여부 | **10%**, 최대 **300만 원** |

### 만기 직전 필수 확인

| 항목 | 내용 |
| :--- | :--- |
| **만기일** | 계좌마다 다름 — 가입일+3년 전후 |
| **연금 전환 기한** | 만기일로부터 **약 60일 이내** |
| **신청 방법** | “ISA 만기 자금 전환” — 일반 이체와 다름 |
| **재가입** | 풍차돌리기 등은 29화 — 본인 상황에 맞는지 별도 판단 |

3년을 채운 뒤 해지해도 **의무기간 미충족 불이익**은 없습니다.
이후는 **출구 전략**의 문제입니다.

## 7. 로드맵 중 급한 돈이 생기면

**원금 범위 중도인출**을 먼저 봅니다.
계좌는 유지되고, 3년 시계도 계속 갑니다.

다만

- 인출분만큼 **납입한도가 복구되지 않음**
- **수익금** 인출은 해지·혜택 영향 가능

그래서 ISA는 **비상금 대체**가 아니라, **투자+절세** 계좌로 두는 편이 마음 편합니다(8화).

---

## 8. 3년 이후 — 그다음은?

만기 후 선택지는 대략 세 가지입니다.

1. **해지 후 일반 투자** — 유연하지만 ISA 혜택 종료
2. **연금계좌 전환** — 추가 세액공제(10%, 최대 300만 원)
3. **재가입·풍차** — 조건·리스크 이해 후(29화)

로드맵은 3년에서 끝나지 않고, **다음 3년을 그릴지**의 분기점입니다.
만기 전에 **핵심 숫자**·관련 회차를 한 번 더 대조해 보세요.

---

## 9. 제 3년을 돌아보며

저는 1년 차에 “납입과 루틴”, 2년 차에 “가족·계좌 역할”, 3년 차에 “만기 출구”를 생각했습니다.
완벽하게 지키진 못했지만, **로드맵이 있었다는 것만으로** 연말·만기 전에 덜 헤맸습니다.

여러분도 달력에 **가입일·만기 예정일·연말 한도 마감** 세 개만 적어 두세요.
ISA는 복잡한 계좌가 아니라 **긴 호흡의 계좌**입니다.

## 11. 로드맵과 제도 변경

한도 상향(4,000만·2억), 비과세 확대(500만·1,000만) 뉴스가 나와도
**확정 전에는 로드맵 숫자를 바꾸지 않습니다.**
확정되면 **그 해 1월**부터 납입·비과세 목표를 조정하면 됩니다.
