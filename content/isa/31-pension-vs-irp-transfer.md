# ISA 만기자금, 연금저축으로 갈까 IRP로 갈까 | ISA계좌 (31화)

안녕하세요.
안대표입니다.

30화에서 만기 60일 안에 연금 전환하는 순서를 정리했습니다.
그다음에 바로 나오는 질문이 이겁니다.

**“받는 계좌를 연금저축으로 할까, IRP로 할까?”**

둘 다 연금계좌라서 비슷해 보이지만,
이미 쓰고 있는 계좌, 직장 퇴직금, 납입 한도, 인출 시점이 다르면 **답이 갈립니다.**

오늘은 ISA 만기 자금의 **목적지 선택**만 집중해서 비교해 보겠습니다.

## 30초 요약

- 연금저축·IRP **모두** ISA 만기 전환 10%·최대 300만 원 공제 대상입니다.
- 차이는 **이미 깔린 연금 인프라** — 퇴직금 IRP vs 연금저축 단순함.
- **60일·전용 절차**는 계좌 유형과 무관하게 동일합니다 (30화).

---

## Q. IRP가 있으면 무조건 IRP로 받아야 하나?

아닙니다. **이미 쓰는 연금계좌가 하나로 정리돼 있다**면 그쪽으로 전환하는 게 답에 가깝습니다.
퇴직금만 있고 추가 납입 계획이 없으면 **연금저축**이 나을 수도 있습니다.

→ [30화: 만기 60일 안에 연금 전환하는 실전 체크리스트](https://mynews20482.tistory.com/30)

## 1. 공통점: ISA 만기 자금 전환 혜택

어디로 넘기든, 제도 요건을 맞추면 공통으로 붙는 게 있습니다.

| 항목 | 내용 |
| :--- | :--- |
| **추가 세액공제** | **이전액의 10%** |
| **공제 한도** | **최대 300만 원** |
| **실무 기한** | 만기일로부터 **60일 이내** 전환 절차 |
| **전제** | ISA 의무가입기간(3년) 충족 후 만기 자금 |

즉 **연금저축이냐 IRP냐**는 “추가 10% 공제” 자체를 가르지 않습니다.
차이는 그 **이후** 운용·한도·인출·기존 계좌와의 궁합에서 납니다.

---

## 2. 연금저축계좌로 받을 때

### 장점

- 구조가 비교적 단순합니다. “연금 모으는 통장”에 가깝죠.
- 이미 연금저축을 쓰고 있다면 **같은 계좌로 이전**해 관리가 편할 수 있습니다.
- 매년 연금저축 납입 세액공제(근로·사업소득 한도 내)와 **별도로** ISA 만기 전환 공제가 붙습니다.

### 단점·주의

- 연금저축도 **연간 납입 한도**가 있습니다. ISA 만기 자금이 한도를 한꺼번에 채울 수 있습니다.
- 55세 이전 중도인출 시 세금·가산세 구조를 따로 봐야 합니다.
- 여러 금융사에 연금저축이 흩어져 있으면, **어느 계좌로 받을지** 정리가 필요합니다.

### 이런 분께 맞을 수 있음

- 퇴직금 IRP가 없거나 단순한 직장인
- 이미 연금저축 하나로 연금을 모으는 중
- 계좌를 늘리기 싫고 **기존 연금저축에 합치고 싶은** 경우

---

## 3. IRP로 받을 때

### 장점

- 퇴직금이 들어가는 **IRP가 이미 있다**면, 연금 자산을 한곳에 모을 수 있습니다.
- ISA 만기 자금 + 퇴직금 + 추가 납입을 IRP 안에서 같이 굴리는 그림이 가능합니다.
- 일부는 IRP 운용 상품 선택지가 넓다고 느끼기도 합니다(금융사별 상이).

### 단점·주의

- IRP는 **퇴직금 계좌 성격**이 섞여 있어, 규칙이 연금저축만 쓸 때보다 복잡하게 느껴질 수 있습니다.
- 추가 납입 한도, 운용·수수료 구조가 금융사·계약마다 다릅니다.
- “IRP가 있으니까 무조건 IRP”는 아닙니다. **퇴직금만 있고 추가 납입을 안 할 계획**이면 연금저축이 나을 수도 있습니다.

### 이런 분께 맞을 수 있음

- 이직·퇴직 경험이 있어 IRP를 이미 운용 중
- 연금 자산을 **한 계좌로 통합**하고 싶음
- 퇴직금과 개인 연금을 같이 리밸런싱하고 싶음

---

## 4. 한눈에 비교

| 구분 | 연금저축 | IRP |
| :--- | :--- | :--- |
| **ISA 만기 전환 10% 공제** | **동일 (최대 300만 원)** | **동일 (최대 300만 원)** |
| **계좌 성격** | 개인 연금 저축 | 퇴직금 + 개인 추가납입 |
| **단순함** | 상대적으로 단순 | 상대적으로 복잡 |
| **기존 계좌 활용** | 연금저축 보유자에게 유리 | IRP·퇴직금 보유자에게 유리 |
| **납입 한도** | 연금저축 한도 별도 확인 | IRP 추가납입 한도 별도 확인 |
| **인출·세금** | 55세 전 인출 시 과세 규칙 확인 | 동일하게 장기 묶임 전제 |

표만 보면 “뭐가 더 낫다”가 안 나옵니다.
**이미 어떤 연금 인프라를 깔아뒀는지**가 답에 가깝습니다.

---

## 5. 금액 설계: 3,000만 원이 전부가 아닐 때

ISA 만기 잔고가 1,000만 원이면, 연금으로 1,000만 원 전환 시 추가 공제는 100만 원입니다.
3,000만 원을 넘기면 공제는 **300만 원에서 멈춥니다.**

그래서 실무에서는

- **공제 한도까지 연금 전환 (최대 3,000만 원)**
- **나머지는 현금·새 ISA·다른 목적**

으로 나누는 경우가 많습니다.

| 만기 잔고 | 연금 전환 | 추가 공제(10%) | 나머지 |
| :--- | :--- | :--- | :--- |
| 2,000만 원 | 2,000만 원 | 200만 원 | 0원 |
| **4,500만 원** | **3,000만 원** | **300만 원** | **1,500만 원** |
| 800만 원 | 800만 원 | 80만 원 | 0원 |

“전액 연금”이 항상 최선은 아닙니다.
**단기에 쓸 돈**까지 연금으로 내면, 나중에 인출할 때 세금 부담이 생깁니다.

연금으로 넘긴 돈은 **55세(또는 제도상 인정 연령) 이전 인출에 세금**이 붙을 수 있습니다.
IRP·연금저축 모두 **장기 묶임** 전제를 같이 봐야 합니다.
ISA 만기 자금을 IRP로 받기로 했다면, **운용보수·입금 수수료**도 연금저축 후보와 비교해 보세요.

## 6. 선택 전에 물어볼 질문 6가지

1. **이미 연금저축·IRP 중 어디에 돈이 더 모여 있나?**
2. **퇴직금 IRP가 따로 있나, 추가 납입까지 할 계획인가?**
3. **만기 60일 안에 처리 가능한 계좌가 열려 있나?**
4. **연금계좌 연간 한도를 ISA 이전으로 다 써버려도 괜찮나?**
5. **55세 전에 이 돈이 필요할 가능성은 없나?**
6. **재가입(풍차)까지 같이 할 건가, 연금이 최종 목적지인가?**

6번이 특히 중요합니다.
29화에서 말했듯, 연금 전환과 ISA 재가입을 **동시에** 하려면 자금 흐름이 꼬이기 쉽습니다.
연금으로 보낸 돈은 ISA 재납입에 바로 쓸 수 없습니다.

## 7. 케이스로 보는 선택

### 케이스 1: 퇴직금 IRP만 있는 직장인

- ISA 만기 2,500만 원 중 **2,500만 원 전환** → 추가 공제 250만 원
- **같은 IRP**로 받으면 연금 자산 한곳 관리
- 이후 매년 연금저축을 따로 만들지 않아도 **퇴직금+ISA** 묶음 운용 가능

### 케이스 2: 연금저축만 여러 은행에 흩어진 경우

- ISA 만기 3,000만 원 → **가장 오래 쓰는 연금저축 하나**로 전환
- 나머지 소액 연금저축은 장기적으로 통합 검토
- IRP가 없다면 **굳이 IRP를 새로 만들 필요는 없음**

### 케이스 3: 연금저축·IRP 둘 다 있는 경우

- **추가 납입을 앞으로도 할 계좌**로 ISA 만기 자금 수령
- 퇴직금만 있는 IRP와 **개인 추가납입 IRP**가 분리돼 있으면, 금융사에 **어느 IRP가 전환 대상인지** 확인

숫자는 예시이며, 실제 공제 체감은 소득·공제 항목에 따라 달라집니다.

## 8. 제가 정리하는 방식

저라면 이렇게 접근할 것 같습니다.

**① 이미 쓰는 연금계좌가 하나로 정리돼 있다**  
→ **그 계좌로 ISA 만기 자금 전환 (60일·전용 절차 확인)**

**② 연금저축과 IRP가 둘 다 있는데 관리가 산만하다**  
→ **장기적으로 한쪽으로 모을 계획을 먼저 세우고, ISA 이전도 그쪽으로**

**③ 연금계좌가 아예 없다**  
→ **ISA 만기 2~3개월 전에 연금저축 또는 IRP 중 하나를 미리 개설** (만기 당일에 급하게 만들면 60일이 빠듯합니다.)

“연금저축 vs IRP”는 이념 싸움이 아니라 **내 연금 지도를 어디에 그릴지** 문제에 가깝습니다.

### 연말정산·종합소득세와의 관계

ISA 만기 자금 **추가 세액공제**는 연금 납입 공제와 **별도**로 붙지만,
연말정산·5월 종합소득세 신고 때 **자료 반영**이 제대로 됐는지 확인하는 습관이 필요합니다.
전환 후 **연말정산 간소화**·납부서·홈택스 내역에 금액이 잡혔는지, 다음 해 5월 전후로 한 번씩 보면 누락을 빨리 잡을 수 있습니다.
