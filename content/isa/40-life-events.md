## Q. 왜 전세 보증금에 ISA를 쓰지 않을까?

전세는 **단기 큰돈**이고, ISA는 **3년·한도 복구 없음·해지 리스크**가 있습니다. 보증금은 **ISA 밖** 안전자산과 짝이 잘 맞습니다.

## 1. 공통 원칙: ISA는 유동성 계좌가 아니다

먼저 전제를 맞춥니다.

- **의무 3년**, 해지·수익 인출에 **세금 리스크**
- **원금 중도인출**은 가능하지만 **한도 복구 없음**
- **만기 연금 전환**은 **60일·전용 절차**
- **연 2,000만·총 1억** 한도는 **인생 이벤트와 경쟁**하는 자금

그래서 전세·집 마련처럼 **단기 큰돈**이 필요한 해에는
ISA를 **“건드리지 않을 돈”** 과 **“뺄 수 있는 돈”** 으로 나눠 생각하는 게 좋습니다.

---

## 2. 이직

### 바뀌는 것

- 월 현금흐름·보너스 시점
- 퇴직금 → **IRP** 이동
- 실직 기간 **유동성** 필요

### ISA와의 접점

| 항목 | 체크 |
| :--- | :--- |
| **납입** | 이직 공백에 **연 2,000만** 못 채울 수 있음 → **이월**(33화) |
| **IRP** | 퇴직금 IRP와 **ISA 만기 연금 전환** 목적지 통합 검토(31화) |
| **해지** | 3년 미만 이직+급전 → **원금 인출** 우선, 해지 지양 |
| **종합과세** | 퇴직 전·후 배당·이자 구조 변화 |

**이직 직후 ISA를 늘리기**보다, **6개월 생활비·전세 보증금**을 ISA 밖에 두고
ISA는 **개설 유지·소액 납입**으로 시계만 돌리는 선택도 있습니다(1화).

---

## 3. 결혼

### 바뀌는 것

- **부부 각 1 ISA** → 한도·비과세 **두 배**(32화)
- 가구 현금흐름·명의·공동 목표
- 서민형 자격이 **둘 다·한쪽만** 해당될 수 있음

### ISA와의 접점

| 항목 | 체크 |
| :--- | :--- |
| **납입 순서** | **서민형**·납입 여력 있는 쪽 우선 |
| **혼전 ISA** | 명의·자금 출처 정리 |
| **예식·혼수** | ISA **원금 인출** vs 다른 저축 |
| **만기 시차** | 부부 ISA **만기·60일** 분산 |

결혼은 ISA **합산 전략**을 시작하기 좋은 타이밍입니다.
반대로 **“우리 ISA”** 라고 부르며 한 계좌만 쓰면 한도 손해가 납니다.

**이혼·별거** 가능성까지 말하기는 어렵지만, **각자 명의·각자 한도**가 법적으로도 맞습니다.

## 4. 전세

### 바뀌는 것

- **보증금** 몰림 (수천만~억 단위)
- 2년 후 **반환**이지만, 그때까지 묶임
- 대출·전세자금대출 이자

### ISA와의 접점

| 질문 | 방향 |
| :--- | :--- |
| 보증금에 ISA 쓸까? | **비추천에 가깝다** — 3년·한도·인출 한도 감소 |
| 전세 직전 ISA 납입? | **유동성 확보 후** 남는 돈만 |
| 전세 기간 중 | ISA **꾸준 소액** vs 한도 미달 이월 |
| 전세 만기 돌려받음 | 그때 **ISA 한도·연말 납입**(33화) 재개 |

전세 보증금은 **ISA 밖 안전자산**(예금·비과세종합저축, 36화)과 짝이 잘 맞습니다.
ISA는 **전세 사이클과 겹치지 않는 장기 돈**에 두는 편이 스트레스가 적습니다.

### 예외적으로 검토할 때

- 의무 **3년 이미 충족** + 만기 + **원금 인출**만으로도 보증금 일부 충당 가능
- 인출해도 **한도 포기**를 감수할 수 있음

그래도 **수익금 인출·해지**는 39화 기준으로 신중히.

## 5. 내 집 마련

### 바뀌는 것

- **주택담보대출·전세대출** 상환
- **취득세·중개비·인테리어** 일시 지출
- 장기적으로 **자가** → 현금흐름 변화

### ISA와의 접점

| 단계 | ISA |
| :--- | :--- |
| **집 구매 1~2년 전** | ISA **무리한 납입** 자제, 유동성 적립 |
| **계약금·잔금** | ISA **해지**보다 **다른 자금** 우선 |
| **입주 후** | 여유 생기면 **연 납입·서민형** 재점검 |
| **만기·연금** | 집 마련 후 **연금 전환 60일**(30화) — 은퇴·상환과 별도 캘린더 |

내 집 마련은 ISA **출구**이기보다 **납입을 잠시 멈추는 구간**으로 보는 경우가 많습니다.
이월 한도는 **집 산 뒤** 다시 쓸 수 있습니다(여유가 생기면).

**주택청약·종잣돈**과 ISA를 같은 돈으로 두 번 쓰지 않도록, **표 하나**로 목적을 나누세요.

## 8. 정리

| 이벤트 | ISA 한 줄 |
| :--- | :--- |
| **이직** | 납입·IRP·유동성, **해지 말고 조절** |
| **결혼** | **부부 2계좌**, 서민형·순서 |
| **전세** | 보증금은 **ISA 밖**, ISA는 장기 |
| **내 집 마련** | 몰아넣기보다 **멈춤·이월**, 만기는 별도 |

ISA는 인생을 기다려주지 않습니다.
대신 **미리 열어두고, 급한 돈과 섞지 않으면** 이벤트가 와도 계좌를 버리지 않아도 됩니다.

저도 집·전세·이직 이야기는 뉴스가 아니라 **달력**으로 옵니다.
ISA도 그 달력에 **작은 칸**으로라도 넣어 두는 편이, 3년 뒤 선택지가 넓습니다.

**출산·육아휴직**처럼 소득이 잠깐 줄어드는 시기에는 ISA 납입을 **줄이고 이월**하는 것도 방법입니다(33화).
무리하게 한도를 채우다 생활비가 꼬이면, 오히려 **원금 인출·해지**로 이어질 수 있습니다.

**내 집 마련 후** 다시 ISA 납입을 늘리는 시점에는, **잔여 총 한도 1억**에서 이미 넣은 금액을 빼 본 뒤 계획하세요.
집 산 뒤에도 ISA는 **남은 한도·이월**로 이어갈 수 있습니다.

**전세 만기 후** 보증금이 돌아오면 ISA 납입을 다시 늘리기 좋은 시점이 됩니다.
다만 “돌아온 돈 전액 ISA”보다 **비상금·다음 전세·집 마련** 목적을 먼저 나눈 뒤, **남는 금액만** ISA에 넣는 편이 안전합니다.
