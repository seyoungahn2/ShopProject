## 1. “우리 집 합산 3,000만”이 위험한 말인 이유

가계부에는 부부 배당을 합쳐 적는 것이 자연스럽다. 세무 합산은 그렇지 않을 수 있다.

- 남편 명의 이자·배당
- 아내 명의 이자·배당

은 각각 **본인 기준**으로 2,000만 원 경계를 본다. (해당 연도·법령 확인)

가계부 합산으로 “이미 종합과세”라고 단정하거나, 반대로 “나눠 있으니 각자 여유”라고만 보면 둘 다 빗나갈 수 있다. **명의별 표**가 먼저다.

## 2. 세금 단위 vs 가구 단위

| 주제 | 기본 단위 | 메모 |
| :--- | :--- | :--- |
| 금융소득종합과세 | **개인** | 이자·배당 합산 |
| 원천징수 15.4% | **소득자·원천징수** | 계좌 명의 |
| ISA | **가입자 개인** | 한도·유형 |
| 피부양자·건보 | **자격·세대 규칙** | 공단 확인 |
| 인적공제 등 | **부양 관계** | 연말·종합과 연결 가능 |

“절세하려고 계좌만 나누면 된다”는 문장은, 위 표의 칸을 무시할 때 나온다.

## 3. 부부 전략을 세울 때 쓰는 질문

1. 각자 일반계좌 이자·배당 합산 추정은?
2. 누가 2,000만 원에 더 가까운가?
3. ISA 한도·유형은 각자 얼마나 남았는가?
4. 피부양자 구조는 어떻게 되어 있는가?
5. 자산을 옮긴다면 **증여·자금 출처** 질문은 준비됐는가?

배당 종목을 바꾸는 이야기와, **누가 보유하는가** 이야기는 층이 다르다. 이 시리즈는 후자만 다룬다.

## 4. 명의 이동을 가볍게 볼 때 생기는 일

부부 사이라도 금융자산을 옮기면 세무·증여 이슈가 생길 수 있다. “가족인데 괜찮겠지”는 점검이 아니다.

실무 태도:

- 목적(경계 관리·건보·상속 대비)을 한 줄로 적는다.
- 금액·시점을 기록한다.
- **전문가·국세청 안내**로 증여 여부·신고를 확인한다.
- 증권 이체 화면의 “완료”를 세무 완료로 착각하지 않는다.

이 글은 증여세 계산을 하지 않는다. **무심코 옮기지 말 것**이 메시지다.

## 5. 세대 관점 체크 (건보·피부양 연결)

6화와 이어지는 가구 점검:

| 점검 | 질문 |
| :--- | :--- |
| 피부양자 | 금융소득으로 자격이 흔들리는 사람은? |
| 지역가입 | 세대 내 소득·재산 부과에 영향이 있는가? |
| 자료 | 배우자 각자 홈택스·증권 자료를 공유해 보는가? |
| 일정 | 세금 5월 / 건보 자격은 **별도 캘린더**인가? |

가구 회의에서는 “올해 배당 목표”보다 **명의별 합산·자격**을 안건으로 올린다.

## 6. 가구 회의 안건 예시 (20분)

1. 각자 합산 추정과 버퍼 공유 (5분)
2. 피부양자·건보 이슈 있는지 (5분)
3. ISA 한도·납입 여력 (5분)
4. 자산 이동이 필요하면 **보류 목록**에만 적기 (5분)

회의에서 종목 이야기를 시작하면 시간이 사라진다. 안건 밖에 둔다.

## 7. 가계부 양식 제안 (절세용)

| 열 | 내용 |
| :--- | :--- |
| 명의 | 본인 / 배우자 |
| 계좌 유형 | 일반 / ISA / 연금 / 해외 |
| 이자 | 연간 추정 |
| 배당 | 연간 추정 |
| 일반 합산 | 이자+배당(특례 제외) |
| 건보 메모 | 피부양·문의 여부 |
| 증여·이동 | 해당 시 날짜·금액 |

가계부 현금흐름 표와 **열을 분리**한다. 입금 일정표에 세금 합산을 섞지 말 것.

## 8. 핵심 숫자

| 항목 | 수치·메모 | 확인 |
| :--- | :--- | :--- |
| **개인 합산 기준** | **2,000만 원** | 명의별 |
| **원천징수** | **15.4%** | 일반 |
| **ISA** | **200만·400만 / 9.9%** | 가입자별 |
| **건보·피부양** | **공단 기준** | 가구 규칙 |

## 9. 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 부부 합산으로 종합과세 판단 | **명의별 합산** |
| 계좌만 바꿔 절세 완료 | **증여·실질·건보** 점검 |
| 가계부=세무 장부 | **세금 표 / 현금흐름 표** 분리 |
| 피부양자 소득을 배우자 합산에 숨김 | **소득자 기준으로 공개** |
| ISA 한도를 부부 공유로 오해 | **가입자 개인 한도** |

## 10. 실전 체크리스트

- [ ] 부부 각자 **합산 추정표**가 있는가
- [ ] 누가 경계에 가까운지 **표시**했는가
- [ ] 피부양자·건보 안건을 **가구 회의**에 넣었는가
- [ ] 자산 이동 시 **증여 확인** 줄을 넣었는가
- [ ] ISA·일반·해외를 **명의×계좌**로 매트릭스화했는가

## 11. 이번 화 전략 (페르소나)

**맞벌이 M (각자 계좌, 합산 감각만 공유)**  
목표: 가계부 합산 착각 제거.  
행동: 엑셀에 시트2개(본인/배우자). 경계 근접자만 ISA·예금 배치를 우선 점검.

**외벌이+피부양 N**  
목표: 세금 경계와 피부양 자격을 동시에 보기.  
행동: 소득자 합산표 + 피부양자 금융소득 메모를 한 대시보드에 두되, 기준 출처(국세청/공단)를 열으로 명시.

## 12. 확인 권장

- **국세청·홈택스**: 종합과세·증여 관련 안내
- **건보공단**: 피부양자·세대 보험료
- **세무사**: 명의 이동·경계 근접
- **금융회사**: 공동/개별 계좌 과세 자료

## 13. 핵심 정리

1. 종합과세 합산은 **개인 명의**로 본다.
2. 가구 전략은 **세금 + 건보 + 증여**를 같은 무게로 올린다.
3. 가계부 합산과 세무 합산을 **섞지 않는 표**가 절반의 절세다.
