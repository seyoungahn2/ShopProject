## 1. 왜 건보가 배당절세 시리즈에 들어오나

세금은 국세청, 건보는 공단이다. 기관이 다르니 기준도 다르다.

그런데 가계가 느끼는 부담은 한 통장에서 나간다. 금융소득이 늘면:

- 종합소득세 이슈와
- 지역보험료·소득월액보험료·피부양자 탈락

이 같은 해에 겹칠 수 있다. “세금은 괜찮은데 건보가 올랐다”는 말이 여기서 나온다.

이 글은 보험료를 Exact하게 계산하지 않는다. **어디에 확인하러 가야 하는지**를 고정한다.

## 2. 가입 유형별로 질문이 다르다

| 유형 | 금융소득이 건드리는 질문 |
| :--- | :--- |
| **직장가입자** | 보수 외 소득이 기준을 넘으면 **소득월액** 이슈가 있는지 |
| **지역가입자** | 소득·재산 보험료 산정에 **이자·배당**이 어떻게 잡히는지 |
| **피부양자** | 소득 요건을 넘어 **자격 상실** 위험이 있는지 |

같은 “배당 1,000만”이라도 유형에 따라 할 일이 다르다. 먼저 **내 자격이 무엇인지** 적는다.

## 3. 세금 경계 ≠ 건보 경계

| 구분 | 자주 쓰는 숫자 | 기관 |
| :--- | :--- | :--- |
| 금융소득종합과세 | 이자·배당 **2,000만** | 국세청 |
| 원천징수 | **15.4%** | 원천징수 의무자 |
| ISA 특례 | **200만·400만 / 9.9%** | 세법 특례 |
| 건보 소득·피부양자 | **별도 기준** | 건보공단 |

“세금이 분리과세로 끝났으니 건보도 끝”은 성립하지 않을 수 있다.  
반대로 “건보만 보면 종합과세는 무시”도 위험하다.

체크리스트를 **세금 표 / 건보 표**로 나눈다.

## 4. 피부양자 점검이 특히 민감한 이유

피부양자는 보험료를 직접 내지 않는 대신, **소득·재산 요건**을 충족해야 한다. 금융소득이 늘면 자격 유지가 흔들릴 수 있다.

실무 습관:

1. 배우자·부모·자녀 중 피부양자 여부를 적는다.
2. 금융소득·사업·기타소득 자료를 **연간 단위**로 모은다.
3. 공단 기준(해당 연도)과 비교는 **공단·자격득실** 안내로 확인한다.
4. 탈락 가능 시 지역가입 전환 보험료를 **시나리오로만** 적어 둔다.

블로그 숫자는 쉽게 낡는다. 여기는 **절차**만 남긴다.

## 5. 절세 행동이 건보에 미치는 간접 효과

ISA로 세금 칸을 바꾸거나, 명의·인출 시점을 조정하는 결정은 **세법 효과**와 **건보 효과**가 다를 수 있다.

| 행동 | 세금 쪽 의도 | 건보 쪽 추가 질문 |
| :--- | :--- | :--- |
| ISA 활용 | 합산·세율 특례 | 공단 소득 반영 방식은? |
| 인출·해지 | 과세 시점 | 소득 귀속 연도는? |
| 세대·명의 | 납세자 단위 | 피부양·세대 규칙과 충돌? |

“세금이 줄어 보이게”만 최적화하면, 건보에서 되돌아올 수 있다. **두 기관 확인**이 기본값이다.

## 6. 세금 표 / 건보 표 예시 헤더

세금 표 헤더 예:

`연도 | 이자 | 배당 | 일반합산 | 원천징수 | 종합과세여부(추정) | 비고`

건보 표 헤더 예:

`연도 | 자격유형 | 금융소득메모 | 피부양해당 | 공단확인일 | 결과메모`

두 표를 한 시트에 붙여 넣지 말 것. 열이 섞이는 순간 “2,000만=건보 기준” 착각이 다시 생긴다.

## 7. 자료는 어디서 모으나

1. 홈택스·지급조서: 이자·배당 규모 감각
2. 증권사·은행: 원천징수·배당 내역
3. **건보공단** 앱·지사: 보험료 부과 점수·소득 반영 안내
4. 자격득실 확인서: 직장/지역/피부양

세금 폴더와 건보 폴더를 물리적으로 나누어 두면, 5월 신고와 보험료 문의가 덜 꼬인다.

## 8. 핵심 숫자

| 항목 | 수치·메모 | 확인 |
| :--- | :--- | :--- |
| **종합과세 기준** | **2,000만 원** | 국세청·해당 연도 |
| **원천징수** | **15.4%** | 일반 이자·배당 |
| **ISA** | **200만·400만 / 9.9%** | 세법 특례 |
| **건보 기준** | **공단 해당 연도** | 세금 숫자로 대체 금지 |
| **제도 변경** | **미확정** 가능 | 확정 공지 우선 |

## 9. 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 세금만 최적화 | **건보·피부양** 병행 점검 |
| 2,000만=건보 기준 | **기관별 기준** 분리 |
| 피부양자 소득을 대략만 짐작 | **연간 자료**로 확인 |
| 공단 상담 없이 SNS 숫자 사용 | **건보공단** 1차 확인 |
| ISA면 건보 무관이라고 단정 | **반영 여부 별도 질의** |

## 10. 실전 체크리스트

- [ ] 내 자격이 **직장 / 지역 / 피부양** 중 무엇인지 적었는가
- [ ] 세금 합산표와 **건보 점검표**를 분리했는가
- [ ] 피부양 가족이 있으면 **소득 요건 확인 일정**을 넣었는가
- [ ] 공단 문의 시 필요한 **금융소득 자료 목록**이 있는가
- [ ] 절세 행동의 **건보 부작용** 질문을 한 줄이라도 적었는가

## 11. 이번 화 전략 (페르소나)

**직장가입자 K (보수 외 소득 증가)**  
목표: 소득월액·부과 이슈를 조기에 발견.  
행동: 연간 이자·배당 추정을 적어 공단·안내에 비춰 볼 질문을 만든다. 세금 종합과세와 별도 줄에 기록.

**피부양 배우자 L**  
목표: 자격 유지 여부를 감이 아니라 자료로.  
행동: 본인 명의 금융소득만 모아 공단 기준과 대조. 필요 시 지역가입 전환 비용을 **가정 시나리오**로만 메모.

## 12. 확인 권장

- **국민건강보험공단**: 보험료 부과, 피부양자 자격
- **국세청·홈택스**: 금융소득·종합과세(세금)
- **세무사·노무사 등**: 개인 상황(역할에 맞게)
- **금융회사**: 원천징수·지급 내역

## 13. 핵심 정리

1. 배당절세의 숨은 축은 **건보·피부양자**다.
2. **2,000만·15.4%·ISA**는 세금 언어이고, 건보는 **공단 언어**다.
3. 절세 행동 전에는 세금과 건보 **두 줄 질문**을 남긴다.
