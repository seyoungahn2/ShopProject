## 1. 주담대를 이자 관점으로 보는 이유

주택담보대출은 금액이 크고 만기가 길다.  
월 납입이 버틸 만해 보여도, 10~30년 누적 이자는 원금의 상당 비율이 될 수 있다.  
그래서 “승인될까”만 묻기보다 **월 원리금·금리 유형·중도상환·대환**을 같이 설계한다.

핵심 용어:

| 용어 | 의미(요지) |
| :--- | :--- |
| **LTV** | 담보가치 대비 대출 비율 |
| **DSR** | 소득 대비 전체 대출 원리금 상환 부담 |
| **LTI 등** | 소득 대비 대출 규모 관련 지표(제도·시점별) |
| **담보** | 주택 등 — 미상환 시 회수 절차 위험이 있음 |

비율·한도 숫자는 지역·주택 수·정책에 따라 바뀐다. **미확정·변경 공지**를 계획에 넣지 말고, 실행 시점 은행 안내를 본다.

## 2. LTV — “집값의 몇 %까지”가 다가 아니다

LTV가 높아질수록 같은 주택에서 빌릴 수 있는 원금이 커지고,  
원금이 커지면 **이자 총액·월 상환**도 커진다.  
한도를 최대로 채우는 것이 항상 이득은 아니다.

실무 질문:

1. 필요 자금인가, **최대 한도**인가  
2. 월 원리금이 소득의 어느 정도인가  
3. 금리 상승(변동) 시에도 유지 가능한가  
4. 중도상환·보너스 상환 계획이 있는가  

담보가 있다고 연체가 무해하지 않다. 연체는 신용·비용·회수 절차로 이어질 수 있다.

## 3. DSR — 가계 전체 빚의 월 부담

주담대만 봐서는 부족하다.  
신용대출·카드론·학자금 등 **모든 대출 원리금**이 DSR에 잡히는 경우가 많다.  
주담대 금리를 낮춰도 다른 고금리 빚이 있으면 현금흐름이 막힌다.

정리 순서 제안:

1. 전체 대출 목록(잔액·월납·금리)  
2. 주담대 월 원리금 시뮬  
3. 고금리 소액부터 정리 가능 여부  
4. 그다음 주담대 한도·금리 협의  

특정 상품 추천이 아니라 **총부채 관점의 순서**다.

## 4. 원리금·만기·거치

장기 만기는 월 납입을 낮추지만 **총이자**를 키우는 경향이 있다.  
거치(이자만)는 초기 부담을 낮추지만 원금이 남아 이자 원천이 유지된다.

| 선택 | 월 부담 | 총이자 경향 | 주의 |
| :--- | :--- | :--- | :--- |
| 만기 길게 | ↓ | ↑ | 장기 금리·소득 변화 |
| 만기 짧게 | ↑ | ↓ | 초기 현금흐름 |
| 거치 후 원리금 | 초기 ↓ | 원금 잔존 시 ↑ | 거치 종료 충격 |

2화의 상환 방식 논의를 주담대 스케줄에 그대로 적용하면 된다.

## 5. 고정·변동·혼합과 주담대

주담대는 혼합형(초기 고정 후 변동)이 흔하다.  
전환 시점의 금리·수수료·조건을 모르면, “고정인 줄 알았는데 어느새 변동”이 된다.

체크:

- 고정 구간 종료일  
- 이후 기준금리·가산  
- 중도상환수수료 면제 시점  
- 금리인하요구·대환 가능 여부  

## 핵심 숫자 (가정 예시)

아래는 **가정 예시**다. 규제 비율·금리는 2026-07 전후에도 수시 변동한다.

| 항목 | 가정·감각 | 확인처 |
| :--- | :--- | :--- |
| 주담대 금리 | **가정 연 3%~6%** | 은행 고시·약정 |
| 금리 1%p·잔액 2억 | **연 약 200만 원** | 단순 이자 감각 |
| LTV·DSR | 정책·개인별 **상이** | 은행·감독 안내 |
| 중도상환수수료 | **가정 0%~1%대** 등 | 약정 조항 |
| 만기 | 10~40년대 상품 존재 | 총이자 시뮬 필수 |

## 흔한 실수 vs 올바른 접근

| 흔한 실수 | 올바른 접근 |
| :--- | :--- |
| 한도 최대만 목표 | **월 원리금+버퍼**로 한도 결정 |
| 주담대만 보고 신용대출 방치 | **DSR·현금흐름**을 통합 관리 |
| 거치=이자 할인으로 오해 | 거치는 **원금 유예** |
| 장기 만기만 선택 | 월액과 **총이자**를 동시에 시뮬 |
| 약정의 변동 전환일 무시 | 캘린더에 **전환·재산정일** 기록 |

## 실전 체크리스트

- [ ] LTV·DSR 관련 안내를 **실행 시점** 은행에서 확인했다  
- [ ] 주담대+기타대출 **월 원리금 합계**를 계산했다  
- [ ] 고정/변동/혼합과 전환일을 약정에서 확인했다  
- [ ] +1%p·+2%p 금리 상승 시 월납을 시뮬했다  
- [ ] 중도상환수수료·일부상환 규칙을 읽었다  
- [ ] 만기·거치 종료를 가계 캘린더에 넣었다  
- [ ] 불법·편법 대출 권유를 거절하는 기준을 정했다  

## 이번 화 전략

**페르소나 A — 생애 첫 주택, 맞벌이**  
승인 한도보다 “금리 상승 후에도 남는 생활비”로 한도를 정한다. 신용대출을 동시에 키우지 않는다.

**페르소나 B — 기존 주담대 보유, 변동금리**  
재산정일과 우대를 점검하고, 여유 시 일부 중도상환으로 잔액 민감도를 낮춘다.

**페르소나 C — 주담대+신용 동시 보유**  
고금리 신용부터 정리 계획을 세운 뒤, 주담대 대환·조건 변경을 검토한다.

## 확인 권장

- **금융감독원·정책금융 공식 안내**: 규제·서민금융(해당 시)  
- **은행 창구·앱**: LTV/DSR 적용, 스케줄, 금리  
- **신용정보**: 기존 대출이 한도에 미치는 영향  
- **등기·감정·약정 서류**: 담보·근저당 조건  

## 핵심 정리

1. 주담대는 **LTV·DSR·금리·만기**가 이자의 뼈대다.  
2. 월 납입뿐 아니라 **총이자·금리 상승 버퍼**를 본다.  
3. 규제·금리는 수시 변동 — **약정·은행 안내**가 기준이다.
