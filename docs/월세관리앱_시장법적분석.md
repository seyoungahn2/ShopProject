# 부동산 월세 관리 앱 — 법적 리스크 · 경쟁 · 투자 관점 분석

> 작성일: 2026-08-05  
> 목적: 집주인–세입자 월세·계약·하자 관리 SaaS의 사업 타당성 검토  
> 핵심 포지션: **중개하지 않음**. 계약서는 부동산/외부 전자계약 산출물을 **보관·관제**만 수행

## 1. 서비스 컨셉 요약

| 구분 | 내용 |
|------|------|
| 문제 | 집주인–세입자 직접 소통의 불편, 월세 미납 추적, 계약서 분실, 파손·변제 분쟁 |
| 해결 | 계약·월세·하자(변제)를 한곳에서 기록·알림·증빙 관리 |

| 선택 확장 | **집주인 본인 월세방 직거래 광고** (당근형 게시판) — 아래 2.1.1 참고 |

비중개 원칙은 유지하되, **“매물 노출” 전체를 금지하는 것이 아니라 “누가·어떤 대가로·얼마나 개입하느냐”** 가 핵심이다.

## 2. 법적 리스크 검토

### 2.1 공인중개사 자격·중개사무소 등록이 필요한가?

**결론: 설계를 지키면 원칙적으로 불필요.**  
단, UX·마케팅·기능이 “알선”으로 읽히면 즉시 리스크가 생긴다.

#### 법령 기준 (`공인중개사법`)

- **제2조 제1호 “중개”**: 중개대상물에 대해 거래당사자 간 매매·교환·**임대차** 등 권리 득실변경에 관한 행위를 **알선**하는 것
- **제2조 제3호 “중개업”**: 타인의 의뢰로 **일정한 보수를 받고** 중개를 **업으로** 행하는 것
- **제9조**: 중개업을 하려면 중개사무소 개설등록 필수
- **제48조 제1호**: 무등록 중개업 → **3년 이하 징역 또는 3천만원 이하 벌금**

대법원 취지(중개행위 판단): 주관적 의사가 아니라, **객관적으로 사회통념상 거래 알선·중개로 보이는지**로 판단한다.

#### Safe / Risky 기능 매트릭스

| 기능 | 중개 해당 가능성 | 권고 |
|------|------------------|------|
| 기존 계약서 PDF/이미지 업로드·암호화 보관 | 낮음 | ✅ 핵심 기능으로 유지 |
| 외부 전자계약(모두싸인, 국토부 IRTS 등) 링크·파일 연동 보관 | 낮음 | ✅ “작성은 외부, 보관은 우리” 문구 고정 |
| 월세 납부 일정·미납 알림·입금 확인 | 낮음 | ✅ |
| 입주/퇴거 체크리스트, 하자·파손 사진·변제 기록 | 낮음 | ✅ 차별화 축 |
| 임대인–임차인 인앱 메시지(기존 계약 당사자만) | 낮음 | ✅ 사후관리 핵심 |
| **집주인 본인** 월세방 광고 + 관심자 직접 연락 (당근형) | 낮음~중간* | ⚠️ 가능. 단 인증·모니터링 필수 (2.1.1) |
| 중개사 매칭, “세입자 구해줌” 성과보수, 타인 물건 대리 광고 | **높음** | 🚫 중개업/불법광고 |
| 앱이 조건을 조율·계약 성사를 **알선** | **높음** | 🚫 |
| 앱 내 임대차계약서 **작성·서명까지 플랫폼이 주도** | **높음** | 🚫 외부 전자계약·당사자 직접 |
| 성사 수수료·보증금/월세 % 수수료 | **높음** | 🚫 광고비·구독만 |
| 갱신·재계약 **알선·수수료** | **높음** | 🚫 단순 알림·템플릿만 |

\*직거래 게시판 자체보다 **무자격 제3자 광고·허위 집주인·플랫폼의 알선형 개입**이 실제 단속·리스크 포인트다.

### 2.1.1 집주인 직접 매물 광고(당근형) — 가능 여부

**짧은 답: 가능에 가깝다. “매물 노출 = 무조건 위험”은 아니다.**  
위험한 것은 **중개형 매물(알선·타인 대리·성사보수)** 이지, **소유자가 자기 월세방을 올리는 직거래 광고**가 아니다.

#### 법적 구분

| 주체·행위 | 취급 | 근거·실무 |
|-----------|------|-----------|
| **소유자(집주인)가 자기 물건을 월세 구함** | 중개 아님 (당사자 광고) | 알선이 아님. 당근·피터팬 등 직거래 모델이 이미 존재 |
| **무자격자가 타인 물건을 “집주인”인 척 광고** | **불법 표시·광고** | `공인중개사법` 제18조의2 ③: 개업공인중개사 아닌 자의 중개대상물 표시·광고 금지. 국토부 표본조사에서 직거래앱 불법광고 다수 적발 |
| **플랫폼이 게시판만 제공**, 연락·협상·계약은 당사자 | 중개업으로 보기 어려움 (정보·광고 매개) | 다만 성사수수료·조건 조율·매칭 개입 시 알선으로 재분류될 수 있음 |
| **직방 ‘집 내놓기’** | 중개사에게 매물 전달 | 직방은 순수 직거래보다 **중개 연결** 쪽. 직거래 분쟁 우려로 직거래 미제공 명시 사례도 있음 |

국토부 입장 요지(보도 기준): 개인 간 직거래를 공인중개사법과 동일하게 규율하는 전용법은 약하고, **허위·사칭 광고 단속 + 플랫폼 운영 가이드(실명인증·집주인 인증)** 로 관리하는 구간이다.

#### 당근형으로 넣을 때 필수 가드레일

1. **본인인증** (통신사 연계 실명) — 국토부가 당근 등에 권고·이행 중인 수준  
2. **집주인 인증**: 등기부등본상 소유자(또는 위임 증빙 있는 관리인)와 게시자 일치 시에만 노출 또는 뱃지  
3. **등록 주체 제한**: 집주인(소유자)만. 중개사·컨설팅·지인 대리 등록 금지(또는 중개사는 별도 라이선스 채널)  
4. **플랫폼 역할 고지**: “직거래 게시·연락 창구. 중개·알선·계약 대행 안 함. 권리분석·계약은 당사자 책임”  
5. **수익**: 노출 광고비·구독만. **계약 성사 % 수수료 금지**  
6. **허위매물 운영**: 거래완료 삭제, 신고·모니터링, 국토부 직거래플랫폼 가이드 준수  
7. **계약 전환**: 직거래로 만난 뒤 → 앱의 **사후관리(월세·하자)** 로 자연 연결 (본업 해자)

#### 사업적으로 남는 리스크 (자격보다 큼)

- 사기·먹튀·허위매물 → **신뢰·브랜드·CS** 리스크 (당근도 동일 이슈)  
- 전세보다 월세는 보증금 규모가 작아 상대적 완화, 그래도 보증금 사기는 존재  
- 중개업계·규제 당국의 모니터링 대상이 됨 → 인증·가이드 준수가 비용

#### 실무적 준수 가이드 (관리 SaaS + 선택적 직거래)

1. **약관 분리 표기**: (A) 체결된 계약의 사후관리 도구 / (B) 집주인 본인 월세 직거래 게시판 — 중개·알선 아님  
2. **사후관리 온보딩**: 기존 계약은 초대 코드 페어링  
3. **직거래 온보딩**: 실명+등기 소유 인증 후에만 월세방 게시  
4. **계약서**: 참고 템플릿·외부 전자계약. 플랫폼이 서명 주체가 되지 않음  
5. **수수료**: SaaS·광고. 성사·중개 유사 성과보수 금지  
6. **변호사 자문**: 출시 전 공인중개사법 제18조의2·직거래 가이드 서면 확인 (본 문서는 법률 자문 아님)

### 2.2 그 외 관련 규제

| 영역 | 포인트 | MVP 영향 |
|------|--------|----------|
| **개인정보보호법** | 주민번호·계좌·계약서·연락처는 민감·고유식별 취급 주의. 최소수집, 암호화, 보관기간, 파기 | 필수: 암호화 저장, 권한 분리, 파기 정책 |
| **전자문서·전자서명** | 외부 플랫폼 산출물 보관은 문제 없음. 자체 전자서명 시 본인확인·감사로그·해시 무결성 필요 | MVP는 첨부 보관으로 충분 |
| **주택임대차보호법 / 민간임대주택법** | 앱이 당사자 권리의무를 창설하지 않음. 등록임대사업자 의무 알림은 편의 기능 | 법률 자문 면책 고지 |
| **부동산 거래신고** | 전월세 신고는 당사자/중개사 의무. 앱은 기한 알림·접수증 보관만 | 신고 대행 시 행정대행 이슈 검토 |
| **전자금융거래법 (PG)** | 월세 **카드결제·정산 대행** 시 PG 등록 이슈. 자금이 플랫폼 계좌를 경유하면 리스크↑ | MVP: 계좌이체 확인·알림만. 결제는 PG 제휴 이후 |
| **여신전문금융업법** | 임대료 카드결제는 원칙적으로 금지 대상이 아니라는 유권해석 사례 있으나, 카드깡 방지·거래확인 강화 요구 | 결제 확장 시 금융 자문 필수 |

### 2.3 법적 리스크 종합 평가

| 리스크 | 수준 | 완화 |
|--------|------|------|
| 무등록 중개 | 설계 준수 시 **낮음**, 알선·성사보수 시 **급상승** | 알선/성과보수 금지, 직거래는 당사자 게시만 |
| 불법 표시·광고 (제3자 사칭 집주인) | 직거래 도입 시 **중간~높음** | 실명+등기 집주인 인증, 대리등록 차단 |
| 개인정보 유출 | **중간** (계약서·계좌·등기) | 암호화, 접근로그, 최소수집 |
| 직거래 사기·허위매물 | **중간** (자격 이슈보다 운영) | 인증 뱃지, 신고, 가이드 준수 |

| 결제/정산 규제 | MVP **낮음**, 결제 도입 시 **높음** | PG 제휴 또는 전자금융업 등록 |

## 3. 경쟁자 분석

### 3.1 대형 부동산 플랫폼 (직방 · 호갱노노 · 다방)

| 플레이어 | 주력 | 월세/임대 **사후관리** | 본 서비스와의 관계 |
|----------|------|------------------------|-------------------|
| **직방** | 매물 검색, 3D/시세, 중개 연결 | 핵심 아님. ‘집 내놓기’로 중개사 연결 | **거래 전** 시장. 사후관리 공백 |
| **호갱노노** (직방 계열) | 아파트 실거래·시세·입주민 게시판 | 집 내놓기 공동 운영으로 **중개 강화** | 정보·중개 중심. 월세 관제 약함 |
| **다방** | 원룸·오피스텔 매물 | ‘우리집’ 등 일부 확장 시도 | 여전히 매물·중개 축 |

**인사이트**: 대형사는 **거래 성사(트래픽·중개 수수료/광고)** 에 최적화되어 있다. 계약 이후 수년간 이어지는 월세·하자·소통은 수익화 우선순위가 낮아, **사후 운영 SaaS는 틈새**로 남아 있다.  
다만 향후 직방 등이 “임대 운영”으로 수직 확장하면 위협이 되므로, **데이터·습관 락인**(납부이력, 하자 타임라인)을 빨리 쌓는 것이 방어책이다.

### 3.2 직접 경쟁 — 개인 임대인용 관리 앱


### 3.4 차별화 기회 (제안 포지션)

경쟁 다수가 **임대인 원사이드(수금·세무)** 에 치우쳐 있다. 사용자 문제 정의의 “직접 소통의 불편 + 파손 변제”는 **양면(임대인↔임차인) + 증빙 타임라인**이 핵심이다.

**권장 차별점**

1. **양면 앱**: 세입자도 납부 증명 업로드, 하자 접수, 입주 상태 사진을 남김  
2. **하자·변제 워크플로**: 발견 → 사진·영상 → 견적/합의 → 보증금 정산 연동 (분쟁 대비 감사 로그)  
3. **중개 제로 브랜딩**: 대형 플랫폼과 법적·제품적으로 명확히 분리  
4. **외부 계약 허브**: 중개사 PDF + 전자계약 파일을 한 계약 카드에 묶음  
5. (중기) **집업페이형 결제 제휴**로 수납은 파트너, 관제는 자사

## 4. 시장 · 경쟁력 · 투자자 관점

### 4.1 시장 규모 (공개 수치 기반)

| 지표 | 수치(추산·공개) | 함의 |
|------|-----------------|------|
| 국내 월세 시장 연간 규모 | 약 **110조원** (업계·언론 추산) | TAM은 결제·금융으로 확장 시 거대 |
| 월세 카드결제 침투율 | **1% 미만** | 디지털화 초기. SaaS·핀테크 여지 |
| 한국 PropTech 플랫폼 시장 | 약 **USD 1.2B** 수준 보고 | 자산관리·PM 세그먼트 성장 |
| 주거에서 월세 비중 | 주거 시장의 상당 비중(보도 기준 약 60%대 언급) | 전세→월세 전환 트렌드와 정합 |

**SAM/SOM (가설적 프레임)**

- SAM: 개인·소규모 다세대/오피스텔 임대인 + 그 세입자 (기관 PMC 제외)  
- SOM (초기 3년): “호실 5~50개 미만 임대인” 중 디지털 도구 수용층  
- 수익: 호실당/계약당 월 구독 + 프리미엄(OCR·세무·알림톡) + 장기적으로 결제 take-rate(제휴)

### 4.2 시장 매력도 (투자자 체크리스트)

| 항목 | 평가 | 근거 |
|------|------|------|
| 문제의 통증 | 높음 | 미납 추적, 카톡 분쟁, 계약서 분실, 보증금 분쟁은 반복 비용 |
| 지불 의지 | 중~높음 | 이미 집요정·온리 등 유료 구독 존재. 무료 마이집사로 가격 민감도도 존재 |
| 네트워크 효과 | 중간 | 양면(임대인–세입자)이면 계약 단위 바이럴. 매물 네트워크만큼은 아님 |
| 해자 | 데이터·습관 | 납부·하자 이력은 이관 비용 발생. 브랜드만으로는 약함 |
| 규제 리스크 | 관리 가능 | 중개 회피 설계 시. 결제 확장 시 급상승 |
| 대형사 진입 | 중기 위협 | 직방 등이 “계약 후 관리”로 오면 유통 파워로 잠식 가능 |
| 확장 옵션 | 높음 | 세무, 보험, 하자 수리 마켓플레이스, 월세 금융(연체·분할), B2B PMC |

### 4.3 비즈니스 모델 시나리오

| 단계 | 모델 | 규제 부담 | 투자 스토리 |
|------|------|-----------|-------------|
| MVP | B2C SaaS 구독 (임대인) + 세입자 무료 | 낮음 | 유닛이코노믹스·리텐션 증명 |
| Growth | 알림톡·OCR·세무 리포트 업셀 | 낮음~중 | ARPU 상승 |
| Scale | 월세 결제 PG 제휴 (집업페이형) | 중~높음 | 거래액 GMV, take-rate |
| Optionality | 보증보험·수리 네트워크·신용 스코어링 | 중 | 데이터 모네타이즈 (동의 기반) |

### 4.4 투자자 관점 밸류에이션 논리 (질적)

**긍정 포인트**

- 명확한 **비중개**로 규제 스토리가 깔끔하고, PropTech 중 “운영 SaaS”는 글로벌에서도 익숙한 카테고리(AppFolio, Buildium 등 비유)
- 월세 현금흐름의 **반복성** → SaaS + (향후) payment 수익의 예측 가능성
- 전세 비중 축소·월세화는 **구조적 테일윈드**

**리스크·디스카운트 요인**

- 국내 **무료·저가 경쟁**(마이집사)으로 CAC·가격 압박
- 양면 마켓은 콜드스타트 어려움 (세입자 앱 설치 유도)
- 대형사 번들 위협
- 결제 미도입 시 매출 상한(순수 SaaS ARPU)이 낮을 수 있음

**투자자가 보고 싶은 초기 지표 (권장 KPI)**

1. 활성 계약 수, 월간 납부 기록률  
2. 임대인 리텐션 (6·12개월)  
3. 세입자 초대 수락률 (양면화 지표)  
4. 하자 티켓 완결까지 소요일·분쟁 재오픈율  
5. 유료 전환율 / 호실당 기여이익

### 4.5 종합 판정

| 관점 | 판정 |
|------|------|
| 법적 실행 가능성 | **가능** — 중개·알선·성과보수를 제품에서 배제하는 한 공인중개사 자격 불필요 |
| 경쟁 공백 | **있음** — 직방·호갱노노는 사후관리 약함. 기존 임대앱은 임대인 원사이드·하자 변제 약함 |
| 시장·투자 매력 | **조건부 매력** — MVP는 SaaS로 PMF 검증 후, 결제·보험 확장으로 업사이드. 단독 SaaS만으로는 엑싯 멀티플이 제한될 수 있음 |

## 5. MVP 범위 제안 (법·경쟁 반영)

### Must (출시)

- 임대인/임차인 계정, 초대 코드로 계약 페어링  
- 계약서·특약 첨부 보관 (암호화)  
- 월세 일정, 납부 확인(수동/이체 증빙), 미납 알림  
- 입주·퇴거 체크리스트 + 사진  
- 하자/파손 접수 → 상태 타임라인 → 합의/변제 메모  
- 약관: 비중개·비자문·개인정보 고지

### Should (직거래 광고를 넣을 경우)

- **월세방만** 집주인 본인 게시 (매매·전세는 범위 밖으로 단순화 가능)  
- 실명인증 + 등기 소유자 일치(집주인 인증) 후에만 노출  
- 관심→채팅은 당사자 간. 플랫폼은 조건 조율·성사보수 없음  
- 계약 성사 후 **같은 앱의 월세·하자 관리로 전환** (핵심 락인)

### Must not

- 무자격 제3자·컨설팅의 대리 매물, 중개사 매칭 알선  
- 계약 성사 % 수수료, 앱이 계약을 “주선·완성”하는 UX  
- 플랫폼 계좌를 통한 월세/보증금 수납(초기)

### Next

- 외부 전자계약 딥링크, OCR 특약 추출  
- 세무 리포트, 내용증명 템플릿  
- PG 제휴 결제, 수리 업체 견적(유지보수 용역으로 구조화·별도 검토)
